### (1) Matplotlib 한글 폰트 및 마이너스 부호 정상화 파이프라인
```python
import matplotlib.pyplot as plt
import pandas as pd

# 1. OS 한글 폰트 및 유니코드 마이너스 깨짐 방지 전역 설정
plt.rcParams['font.family'] = 'Malgun Gothic'
plt.rcParams['axes.unicode_minus'] = False

    "월": ["1월", "2월", "3월", "4월", "5월"],
    "매출": [3500, 4200, 3800, 5100, 4900]

df_sales = pd.DataFrame(sales_data)

plt.figure(figsize=(8, 4))
plt.plot(df_sales["월"], df_sales["매출"], marker="o", color="royalblue", label="월별 매출")

plt.ylabel("매출 (KRW)", fontsize=10)
plt.grid(True, linestyle="--", alpha=0.6)
plt.legend(loc="upper left")
plt.tight_layout()
plt.show()
```

### (2) 대용량 SQLite에서 경량 샘플 DB 추출 및 압축(`VACUUM`)
```python
import sqlite3
from pathlib import Path

# 600MB 원본 DB에서 GitHub 배포용 15MB 샘플 DB 추출
src_db = Path("sampledata/temp/20240102_LOB.db")
dst_db = Path("sampledata/temp/sample_LOB.db")

src_conn = sqlite3.connect(src_db)
dst_conn = sqlite3.connect(dst_db)

TARGET_STOCKS = ["000270", "005930"]  # 기아, 삼성전자
for stock in TARGET_STOCKS:
    # 스키마 복제
    create_sql = src_conn.execute(f"SELECT sql FROM sqlite_master WHERE type='table' AND name='{stock}';").fetchone()[0]
    dst_conn.execute(create_sql)
    
    # 데이터 복제
    rows = src_conn.execute(f"SELECT * FROM '{stock}'").fetchall()
    placeholders = ",".join(["?"] * len(rows[0]))
    dst_conn.executemany(f"INSERT INTO '{stock}' VALUES ({placeholders})", rows)

dst_conn.commit()
dst_conn.execute("VACUUM;")  # 빈 페이지 정리로 파일 크기 최소화
src_conn.close()
dst_conn.close()
```

## 3. 트러블슈팅 및 해결 (Troubleshooting & Resolution)

### Issue 1: 프로젝트 경로 변경 후 가상환경 `.venv` 모듈 인식 불가
* **원인:** 파이썬 가상환경(`.venv`)은 생성 시 `pyvenv.cfg` 및 내부 바이너리 스크립트에 원래 폴더의 절대 경로가 하드코딩되므로, 폴더를 복사/이동하면 내부 경로 링크가 전부 깨짐.
* **해결:** 깨진 `.venv`를 복구하려 하지 않고 `Remove-Item -Recurse -Force .venv`로 즉시 삭제한 뒤, 루트에서 `uv sync`를 실행해 1초 만에 새 경로 기준으로 클린 재구축 완료.

### Issue 2: Matplotlib 차트의 한글 글리프 미지원 및 마이너스 부호 깨짐
* **원인:** 기본 폰트(`DejaVu Sans`)에 한글 유니코드 글리프가 없고, 축 눈금 렌더링 시 유니코드 마이너스 부호(`\u2212`)와 ASCII 마이너스(`-`) 간의 충돌 발생.
* **해결:** `plt.rcParams['font.family'] = 'Malgun Gothic'` 및 `plt.rcParams['axes.unicode_minus'] = False` 2줄 설정을 시각화 스크립트 최상단에 관용구로 고정.

### Issue 3: SQL `WHERE` 절에서 `SELECT` 계산식 별칭 참조 시 실행 에러
* **원인:** SQL 파이프라인의 물리 실행 순서는 `FROM` ➔ `WHERE` ➔ `GROUP BY` ➔ `HAVING` ➔ `SELECT` ➔ `ORDER BY` 순임. `WHERE` 절이 평가되는 시점에는 `SELECT` 절의 별칭(Alias)이 메모리에 존재하지 않음.
* **해결:** `WHERE total_price >= 10000` 대신 원본 수식인 `WHERE price * quantity >= 10000` 형태로 쿼리를 작성하여 필터링 단계 충족.

### Key Takeaways
1. **자원 관리의 표준화**: 파일 I/O는 `with open(..., encoding="utf-8-sig")` 컨텍스트 매니저를 통해 자원 누수를 방지하고, Windows 환경의 CSV 생성 시에는 `newline=""`을 지정하여 중복 개행을 원천 차단한다.
2. **직렬화 포맷 선택 기준**: 단순 평면 표 데이터는 `CSV`, 계층적 딕셔너리/불리언/수치형 구조의 무손실 보존에는 `JSON(dump/load)`을 적용한다.
3. **DB 아키텍처와 인덱스 원리**: `PRIMARY KEY`는 DBMS가 내부적으로 고유 B-Tree 인덱스를 자동 생성하지만, `FOREIGN KEY`는 자동 인덱싱되지 않으므로 실무 조인 성능을 위해 수동 인덱스 설정이 필수적이다.
4. **대용량 데이터셋 형상 관리**: 600MB급 원본 DB는 `.gitignore`로 격리하고, `VACUUM`을 거친 초경량 샘플 DB(`sample_LOB.db`)만 리포지토리에 포함시켜 프로젝트의 100% 재현성과 경량성을 동시에 확보한다.
5. **터미널 & IDE 표준화**: 객체 지향 파이프라인인 PowerShell과 영문 인터페이스를 기본으로 통일하여 도구 간 호환성과 트러블슈팅 효율을 극대화한다.
