## 2. 🔬 직접 실험 및 핵심 학습 내용

### 2.1. RDBMS 핵심 원리와 DDL / DML 실전
- **부동소수점 오차와 `DECIMAL`:** 2진수 기반 부동소수점(`FLOAT/DOUBLE`)의 연산 오차($1.1 + 0.1 \neq 1.2$)를 방지하기 위해 금융/가격 데이터에는 고정소수점 타입(`DECIMAL(p, s)`)을 필수로 사용해야 함을 확인.
- **DDL vs DML 구분:**
  - **DDL (그릇 다루기):** `CREATE TABLE`, `DROP TABLE`, `ALTER TABLE` (외래키 종속성 고려하여 자식 $\rightarrow$ 부모 순으로 DROP).
  - **DML (음식 다루기):** `INSERT INTO ... VALUES (), ()` 다중 행 벌크 삽입으로 트랜잭션 오버헤드 단축, `SELECT`, `WHERE`, `ORDER BY`.
- **`UNIQUE`와 `NULL`의 관계:** SQL에서 `NULL`은 '값이 없음(Unknown)'이므로, `UNIQUE` 제약조건이 걸려 있어도 `NULL`은 무제한 중복 삽입이 가능함.

### 2.2. 정규화(Normalization)와 ERD 내비게이션
- **1NF:** 모든 컬럼 값은 원자값(Atomic Value)이어야 함 (콤마로 묶인 배열형 데이터 분리).
- **2NF:** 복합 기본키의 일부에만 종속되는 부분 함수 종속 제거 (학생-강의 수강 테이블 분리).
- **3NF:** 기본키가 아닌 일반 컬럼에 종속되는 이행적 함수 종속 제거 (고객 등급 코드-등급명 분리).
- **N:M 관계 해소:** RDB는 다대다 관계를 직접 저장할 수 없으므로 **중간 연결 테이블(Junction Table)**을 두어 $1:N$ 2개로 분해.
- **ERD 까마귀발 표기법:** `||`(정확히 1개), `O<`(0개 이상 선택적 다수), `|<`(1개 이상 필수 다수) 기호를 읽고 JOIN 징검다리 경로 탐색.

### 2.3. 데이터 조회 및 가공 (Kaggle Bike Store & Olist Dataset)
- `DISTINCT`를 통한 고유 카테고리/지역/상태값 추출.
- `WHERE` 다중 조건문 (`BETWEEN`, `IN`, `LIKE '%pattern%'`, `IS NOT NULL`, `AND / OR`).
- `CASE WHEN ... THEN ... ELSE ... END AS` 조건부 파생 컬럼 생성.
- `ORDER BY col1 ASC, col2 DESC` 다중 컬럼 정렬 우선순위 적용.

### 2.4. 퀀트 플랫폼 통합 아키텍처 (`Stock` + `Stock-dashboard`)

## 3. 🛠️ 트러블슈팅 및 해결 (Troubleshooting)

### [Issue 1] DBeaver CSV Import 시 해시 문자열 ID 파싱 에러
- **문제:** Olist 데이터셋의 32자리 해시 ID(`b2b60...`)를 DBeaver가 `Numeric(숫자)`으로 자동 감지하여 `Can't parse numeric value using formatter` 에러 발생 및 임포트 중단.
- **원인:** DBeaver 마법사의 소스 컬럼 포맷터 캐시가 숫자 타입으로 고정됨.
- **해결:** SQL에서 대상 테이블의 ID 컬럼들을 `TEXT` / `VARCHAR(50)`로 명시한 DDL을 먼저 일괄 실행(`DROP TABLE ... CASCADE` 후 `CREATE TABLE`)하고, 신규 매핑으로 데이터를 적재하여 완벽 해결.

### [Issue 2] DBeaver 멀티 데이터베이스 생성 차단 오류
- **문제:** `Cannot create a database when multi-database mode is disabled.` 팝업 발생.
- **원인:** PostgreSQL 연결 설정이 단일 DB 모드(기본 `postgres`만 표시)로 제한되어 있음.
- **해결:** 연결 설정(`Edit Connection`) $\rightarrow$ `PostgreSQL` 탭 $\rightarrow$ **`모든 데이터베이스 표시 (Show all databases)`** 체크 활성화로 프로젝트별 독립 DB 생성 환경 구축.

### [Issue 3] PowerShell 가상환경 및 REPL 명령어 입력 오류
- **문제:** `python - m venv` 오타로 인해 파이썬 인터프리터(`>>>`)가 실행되었고, 내부에서 `pip install`과 `streamlit run`을 한 줄로 실행하여 `SyntaxError` 발생.
- **원인:** REPL 환경과 셸 CLI 환경의 혼동 및 패키지 설치/앱 실행 명령어 인라인 병합.
- **해결:** `exit()`로 탈출 후, 표준 패키지 매니저 `uv`를 사용해 `uv venv` $\rightarrow$ `uv pip install -r requirements.txt streamlit` $\rightarrow$ `uv run streamlit run app.py` 3단계로 분리 실행하여 정상 렌더링 확인.
