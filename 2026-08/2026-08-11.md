## 1. Python 제어문: 반복문 (Chapter 4-2 & 4-3)

### 1.1 `for`문과 `while`문의 핵심 차이
- **`for`문:** 순회할 시퀀스 데이터(리스트, 튜플 등)나 정해진 범위(`range`)가 명확할 때 사용 (안전성 높음, 실무 사용률 80% 이상).
- **`while`문:** 정확한 반복 횟수를 모르지만 특정 조건이 참(True)인 동안 계속 실행해야 할 때 사용 (종료 조건 미비 시 무한 루프 주의).

### 1.2 `range()` 함수의 규칙
- `range(시작값, 끝값, 증감폭)`: **시작값 이상, 끝값 미만**의 경계 규칙이 적용됨.
- `range(1, 7, 2)` $\rightarrow$ `1, 3, 5` 생성.

### 1.3 루프 제어 키워드
- **`break`:** 가장 가까운 반복문 전체를 즉시 탈출.
- **`continue`:** 하위 실행 구문을 생략하고 다음 반복 회차로 점프.

### 1.4 통계 지표 산출 알고리즘 (내장함수 미사용)
데이터의 크기나 음수 여부를 모를 때 최댓값/최솟값을 안전하게 구하려면 **첫 번째 요소(`data[0]`)를 기준값**으로 설정해야 함.

min_val = scores[0]
total = 0

for score in scores:
    if score > max_val:
        max_val = score
    if score < min_val:
        min_val = score
    total += score

## 2. Python 함수와 매개변수 (Chapter 5-1)

### 2.1 함수의 본질 및 발음
- **정의 및 읽기:** `def` 키워드는 **"데프"**[deaf]라고 읽는 것이 현업 및 미국/영미권 공통 표준.
- **역할:** 특정 로직을 재사용 가능한 상자로 독립시켜 코드 중복을 제거.

### 2.2 인자의 종류
1. **위치 인수 (Positional Arguments):** 정의된 순서대로 주입 (`func("민수", 25)`).
2. **키워드 인수 (Keyword Arguments):** 매개변수명을 직접 지정 (`func(age=25, name="민수")`).
   * *주의:* 위치 인수를 키워드 인수보다 반드시 앞에 써야 함!
3. **기본값 매개변수 (Default Parameter):** 미리 기본값을 대입해 두는 매개변수 (`def func(name, level="Basic"):`).
   * *주의:* 기본값이 없는 매개변수를 항상 앞쪽에 배치해야 함.

### 2.3 가변 인수 (`*args` vs `**kwargs`)
- **`*args` (가변 위치 인수):** 개수 제한 없이 값을 받아 내부에서 **`튜플(Tuple)`**로 묶어서 처리.
- **`**kwargs` (가변 키워드 인수):** `key=value` 형태로 받아 내부에서 **`딕셔너리(Dictionary)`**로 처리.

### 2.4 `print()` vs `return` & 튜플 언패킹(Unpacking)
- **`print()`:** 화면 출력용 (반환값은 `None`).
- **`return`:** 계산된 결과값을 함수 밖으로 전달하고 함수 종료.
- **다중 반환과 언패킹:** 쉼표(`,`)로 여러 값을 반환하면 튜플로 묶여 나가며, 이를 개별 변수로 나누어 받을 수 있음.

```python
def calculate_total(price, delivery_fee=3000):
    total = price + delivery_fee
    return total, "결제가 완료되었습니다"  # 튜플로 다중 반환!

# 튜플 언패킹 (Unpacking)
total_price, payment_msg = calculate_total(25000)
print(total_price)   # 28000
print(payment_msg)   # 결제가 완료되었습니다
```

## 3. 파이썬 심화 팁 및 문법 Q&A

### Q1. `range(1, 101)`과 `random.randint(1, 100)`은 왜 다른가요?
- 파이썬의 표준 규칙은 **"이상~미만"** (`range(1, 101)` $\rightarrow$ 1~100)이지만, `randint(1, 100)`은 일반인의 주사위 던지기 직관(이상~이하)을 반영한 예외적인 함수임.
- `range`와 동일한 이상~미만 규칙을 적용하고 싶다면 **`random.randrange(1, 101)`**를 사용.

### Q2. 클래스 내부의 `self.`은 무슨 역할인가요?
- `self.`은 **"이 객체 자신(My)"**의 변수임을 나타냄.
- 함수 내부에서 `self.` 없이 만든 변수는 함수가 끝날 때 삭제(지역 변수)되지만, `self.변수명`으로 만든 변수는 **객체가 유지되는 동안 지속되며 다른 메서드 간에 공유** 가능.

## 4. 데이터 구조: Dictionary vs Pandas DataFrame

| 구분 | Dictionary (`dict`) | Pandas DataFrame (`df`) |
| :--- | :--- | :--- |
| **비유** | 단일 메모장 / 보관 상자 | 풀 옵션 엑셀 프로그램 |
| **주 목적** | 단건 데이터 저장 및 빠르게 조회 | 대량 데이터 통계, 그룹화(`groupby`), 전처리 |
| **내부 작동** | **해시 테이블 (Hash Table)** 사용 ($O(1)$) | **해시 테이블 (인덱스/컬럼명)** + **C-NumPy 연속 메모리 (실제 데이터)** |
| **순회 방식** | `for key in dict:` | **`df.iterrows()`**, **`df.itertuples()`** 또는 **벡터 연산** |

> 💡 **Pandas 최고 팁:** 데이터프레임 처리 시 `for`문을 돌리면 매우 느리므로, `df['총점'] = df['국어'] + df['영어']` 처럼 **벡터 연산**을 쓰는 것이 표준!
