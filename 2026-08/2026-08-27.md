## 1. 문제 인식 (Problem Recognition)

### ① 시각화 라이브러리 및 런타임 호환성 이슈
* **Python 3.12+ 내장 모듈 삭제 충돌:** `uv add koreanize_matplotlib` 설치 후 임포트 시 `distutils` 부재로 인한 `ModuleNotFoundError` 발생 (PEP 632로 `distutils`가 표준 라이브러리에서 영구 제거됨).

* **Matplotlib OOP 객체 지향 인터페이스 혼선:** `plt.subplots(1, 3)`에서 반환된 `axes` 배열을 `for ax, bins in zip(...)` 형태로 순회할 때의 개별 캔버스 할당 원리 및 `figsize=(w, h)`의 전체 도화지 크기 스케일링 메커니즘 정립 필요.

### ② AI 에이전트(Agent) 인프라 및 API Rate Limit (429) 병목
* **Agent vs Model vs MCP 개념 분리:** 단순 챗봇 모델(LLM), 터미널 제어 도구(CLI), 외부 도구 표준 연결 규격(MCP), 자율 실행 에이전트(Agent) 간의 아키텍처적 경계 모호.
* **API Quota Exhausted (HTTP 429):** Google Gemini Pro Preview 모델 연결 시 무료 티어 한도(`limit: 0`)로 인한 요청 차단 및 Flash 모델에서 에이전트의 순간 연속 호출(Burst Request)로 인한 RPM(1분당 15~20회) 일시적 신호등 걸림 현상 직면.
* **로컬 LLM 도구 호출 한계:** 로컬 Ollama 환경(`llama3.2:3b`)을 에이전트에 붙였을 때 소형 모델의 XML/JSON Tool Calling 파싱 실패 가능성 확인.

### ③ 70만 행 KRX 금융 시세 데이터의 도메인 특화 품질 결함
* **메타데이터 1:N 불일치 노이즈:** 동일 종목코드(`srtnCd`)에 상장명 변경/약칭 혼용으로 복수의 종목명(`itmsNm`, 예: '맵스리얼티' $\leftrightarrow$ '맵스리얼티1')이 매핑되어 Groupby 집계 시 레코드가 쪼개지는 현상 발견.
* **통계적 이상치 vs 금융 도메인 에러:** 일반적인 $IQR$ 기준 이상치 외에 $High < Low$, $Close$ 범위 이탈, 거래량 0주 가격 변동, 일일 회전율 100% 초과 등 퀀트 백테스팅 무결성을 해치는 도메인 에러 검증 필요.

## 2. 직접 코드 실험 (Direct Code Experiment)

### [실험 1] OS 종속성 없는 네이티브 한글 폰트 & 서브플롯 OOP 순회 렌더링
```python
import platform
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd

# 1. OS별 네이티브 폰트 동적 설정 (외부 패키지 의존성 완전 제거)
if platform.system() == "Windows":
    plt.rcParams["font.family"] = "Malgun Gothic"
elif platform.system() == "Darwin":
    plt.rcParams["font.family"] = "AppleGothic"
else:
    plt.rcParams["font.family"] = "NanumGothic"
plt.rcParams["axes.unicode_minus"] = False

# 2. subplots OOP 인터페이스 검증 (전체 figsize=(15, 4) 분할)
data = np.random.randn(1000)
fig, axes = plt.subplots(1, 3, figsize=(15, 4))  # 1행 3열 도화지 생성

# zip을 통한 서브플롯 개별 캔버스(ax) 및 파라미터 매핑 순회
for ax, bins in zip(axes, [5, 30, 100]):
    ax.hist(data, bins=bins, color="steelblue", edgecolor="white")
    ax.set_title(f"Histogram (bins={bins})")
    ax.set_xlabel("Value")
    ax.set_ylabel("Frequency")

plt.tight_layout()
plt.show()
```

### [실험 2] KRX 금융 시세 데이터 도메인 무결성 & 1:N 노이즈 전수 탐지 엔진
```python
from pathlib import Path
import pandas as pd

ROOT = Path(__file__).resolve().parent
INPUT_PATH = ROOT / "data" / "한국_금융데이터.csv"
OUTPUT_DIR = ROOT / "data" / "processed"
OUTPUT_DIR.mkdir(parents=True, exist_ok=True)


def detect_stock_market_anomalies(df: pd.DataFrame) -> None:
    total_rows = len(df)
    print(f"📊 총 레코드 수: {total_rows:,}행 | 대상 컬럼: {len(df.columns)}개")

    # 1. 1:N 종목명 불일치 (맵스리얼티 등 메타데이터 노이즈)
    name_check = df.groupby("srtnCd")["itmsNm"].nunique()
    multi_names = name_check[name_check > 1]
    print(f"👉 1:N 명칭 불일치 종목코드 수: {len(multi_names):,}개")

    if len(multi_names) > 0:
        conflicted = (
            df[df["srtnCd"].isin(multi_names.index)][["srtnCd", "itmsNm"]]
            .drop_duplicates()
            .sort_values("srtnCd")
        )
        conflicted.to_csv(
            OUTPUT_DIR / "anomaly_name_mismatch.csv",
            index=False,
            encoding="utf-8-sig",
        )
        print("💾 ➔ 'anomaly_name_mismatch.csv' 추출 완료")

    # 2. OHLC 가격 논리 모순 탐지 (도메인 무결성)
    err_hl = df[df["hipr"] < df["lopr"]]
    err_clpr = df[(df["clpr"] > df["hipr"]) | (df["clpr"] < df["lopr"])]
    err_negative = df[(df["clpr"] <= 0) | (df["trqu"] < 0)]

    print(f"👉 High < Low 모순 건수           : {len(err_hl):,}건")
    print(f"👉 Close가 [Low, High] 이탈 건수   : {len(err_clpr):,}건")
    print(f"👉 주가/거래량 음수 이하 건수      : {len(err_negative):,}건")

    # 3. KRX 상하한가 규정(±30%) 초과 등락률 탐지
    extreme_flt = df[abs(df["fltRt"]) > 30.0]
    print(
        f"👉 ±30% 초과 등락 건수(신규상장/권리락 검토): {len(extreme_flt):,}건"
    )

    # 4. 무거래량 주가 변동 탐지
    zero_vol_chg = df[(df["trqu"] == 0) & (df["vs"] != 0)]
    print(f"👉 거래량 0주 주가 변동 건수: {len(zero_vol_chg):,}건")


# 실행 검증

```

## 3. 트러블슈팅 및 해결 (Troubleshooting & Resolution)

### Issue 1: `koreanize_matplotlib`의 Python 3.12+ `distutils` 종속성 충돌
* **현상:** `uv add koreanize_matplotlib` 후 `import koreanize_matplotlib` 실행 시 `ModuleNotFoundError: No module named 'distutils'` 예외 발생.
* **원인 분석:** Python 3.12부터 폐기(Deprecated)되었던 표준 모듈 `distutils`가 완전히 제거됨. 구버전 패키지가 `from distutils.version import LooseVersion`을 호출하여 런타임 크래시 발생.
* **해결:** 외부 호환 패키지에 의존하지 않고, 스크립트 상단에 `plt.rcParams['font.family'] = 'Malgun Gothic'` 및 `plt.rcParams['axes.unicode_minus'] = False`를 명시하는 네이티브 방식으로 리팩토링.

### Issue 2: `pd.concat` 후 Seaborn Boxplot 렌더링 시 Duplicate Labels 에러
* **현상:** `combined = pd.concat([online, offline])` 후 `sns.boxplot(data=combined, x='channel', y='revenue')` 실행 시 `ValueError: cannot reindex on an axis with duplicate labels` 발생.
* **원인 분석:** 결합 대상 데이터프레임들의 인덱스가 모두 `0, 1, 2...`로 시작하여 결합 결과 데이터프레임 내에 중복 인덱스 레이블이 존재함. Seaborn 카테고리 내부 재색인(Reindexing) 과정에서 예외 트리거.
* **해결:** `pd.concat([online, offline], ignore_index=True)`로 인덱스를 재정렬하여 무결성 확보.

### Issue 3: Google Gemini API 연결 시 `429 RESOURCE_EXHAUSTED` 및 에이전트 행(Hang)
* **현상:** Cline에서 `gemini-3.1-pro-preview` 설정 시 `Thinking...` 상태 후 `limit: 0`과 함께 429 에러 3회 반복 후 정지.
* **원인 분석:** 구글 무료 티어에서 무거운 Pro Preview 모델의 할당량(Quota)을 0으로 차단함. 또한 Flash 모델 전환 후에도 에이전트가 파일 읽기/터미널 실행을 수초 내 폭발적으로 호출(Burst)하여 1분당 속도 제한(15~20 RPM)에 순간적으로 걸림.
* **해결:** 
  1. 모델을 완전 무료 티어가 보장되는 `gemini-2.0-flash`로 변경.
  2. 프롬프트에 *"단계별로 차근차근 확인하며 진행해줘"* 지시어를 추가하여 Burst 호출 완화.
  3. 일시적 429 발생 시 5초 쿨타임 후 `[Retry]`를 수행하거나, 복수 Google 프로젝트 키를 준비하여 전환.

### ② 패키지 매니저: `pip install` vs `uv add`의 결정론적 차이

| 비교 항목 | `pip install <pkg>` | `uv add <pkg>` |
| :--- | :--- | :--- |
| **작동 메커니즘** | 활성 가상환경(`.venv`)에 패키지 파일만 다운로드 | 가상환경 설치 + **`pyproject.toml` 및 `uv.lock` 자동 갱신** |
| **의존성 재현성** | 수동 `pip freeze` 없이는 환경 유실 위험 | **해시 기반 락파일로 언제 어디서나 100% 동일 환경 복원 (`uv sync`)** |
| **성능 (속도)** | Python 인터프리터 기반 (수십 초 소요) | **Rust 기반 초고속 병렬 다운로드 & 빌드 (10~100배 고속)** |
| **패키지 정리** | `pip uninstall` (설정 파일 수동 정리 필요) | **`uv remove <pkg>` (파일 + TOML + 락파일 원자적 정리)** |
