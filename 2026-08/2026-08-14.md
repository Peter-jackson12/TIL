## 3. 트러블슈팅 및 해결 (Troubleshooting & Resolution)

### Issue 1: Pandas DataFrame 라벨 인덱싱(`[0]`)으로 인한 백테스팅 예외 발생
* **원인:** `df[code_col][0]`으로 접근 시, 데이터프레임의 정수 인덱스가 0부터 시작하지 않거나 슬라이싱되었을 때 `KeyError` 발생 ➔ `try-except`에 걸려 해당 종목 백테스팅이 스킵됨.
* **해결:** 위치 기반 절대 인덱싱인 `.iloc[0]`을 사용하여 인덱스 구조와 상관없이 0번째 행 데이터(종목명)를 안전하게 가져옴.

### Issue 2: 빈 리스트(`[]`) 검증 시 `all()`의 보완적 조건식 필요
* **원인:** `all([])`은 내부 동작상 `False` 요소가 없으므로 `True`를 반환 ➔ 필수 약관 리스트 자체가 누락(`[]`)되었을 때 검증을 통과하는 보안 취약점 발생.
* **해결:** 단락 평가(Short-circuiting)를 활용하여 `if user_inputs and all(user_inputs):` 형태로 **존재성 검증을 선행 배치**함으로써 가볍고 안전하게 조건 차단.

### Issue 3: Git Detached HEAD 상태 복구
* **원인:** 특정 커밋으로 강제 이동 후 브랜치가 커밋 해시에 분리된(Detached) 상태 지속.
* **해결:** `git checkout -B main` 명령어로 현재 정상 작동하는 커밋 위치로 `main` 브랜치를 강제 재설정 및 복구 완료.

3. **조건식 성능 최적화:** `and` 연산 시 연산량이 가볍고 `False`가 나올 확률이 높은 조건을 앞에 배치하여 단락 평가(Short-circuiting)를 유도하는 것이 실행 속도 향상에 유리함.
