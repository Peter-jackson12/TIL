## 1. 🛠️ 퀀트 백테스팅 엔진 실전 디버깅 및 한글 종목명 매핑

### 1.1 `engine.py` 빈 CSV 생성 및 숨겨진 에러 해결
* **문제:** `main.py` 실행 시 결과 CSV가 0바이트 빈 파일로 생성됨.
* **원인:** `_process_stock` 메서드 하단에 `try: ... except Exception: pass` 구문이 들어있어서, SQLite 수치 형변환 과정에서 일어난 에러를 터미널에 띄우지 않고 조용히 감추고 있었음.
* **해결:** `except` 블록에 `traceback.print_exc()`를 복구하여 에러를 표출시키고, SQLite 칼럼을 `np.array(raw_data[1]).astype(float)`로 강제 형변환하여 타입 에러를 차단함.

## 2. 📚 Python 핵심 문법 정리

### 2.1 예외 처리 (`try-except-else-finally` & `raise`)
* **`SyntaxError` vs `Exception`:** `SyntaxError`는 문법 규칙 위반으로 실행 전에 차단되는 오류이며, `Exception`은 실행 도중 부적절한 연산 시도로 발생하는 런타임 에러임.
* **실행 순서:** `try` (실행) ➔ `except` (에러 대응) / `else` (에러 없이 성공 시만 실행) ➔ `finally` (성공/실패 관계없이 무조건 최종 실행).
* **`raise` 키워드:** 문법상은 정상이지만 서비스/비즈니스 규칙에 어긋나는 부적절한 데이터(예: 음수 수량) 진입 시 의도적으로 에러를 내어 시스템 데이터 무결성 유지.

### 2.2 디버깅 기초 (VS Code Debug Cell)
* **Traceback 해석:** 호출 스택(Call Stack) 역추적 리포트로, 가장 아래쪽의 예외 이름과 메시지를 먼저 확인한 뒤 위로 올라가며 에러 발생 함수를 진단.
* **디버거 제어 명령어:**
  * **`Step Over`:** 함수 내부 진입 없이 현재 줄 실행 후 다음 줄 이동
  * **`Step Into`:** 호출된 함수 내부의 첫 번째 소스 줄로 직접 진입
  * **`Step Out`:** 현재 탐색 중인 함수 남은 로직을 마저 실행하고 부모 위치로 복귀
  * **`Continue`:** 다음 중단점(Breakpoint, `●`)을 만날 때까지 연속 실행

### 2.3 클래스(Class)와 객체지향(OOP)
* **클래스(Class) vs 인스턴스(Instance):** 추상적인 설계도(Class)와 실제 힙 메모리에 할당된 데이터 실체(Instance).
* **생성자 `__init__` & `self`:** 인스턴스화 시점에 자동 실행되어 속성을 초기화하는 매직 메서드. `self`는 현재 동작 중인 '인스턴스 자기 자신'의 메모리 주소를 가리킴.
* **메모리 독립성:** 동일한 클래스로 생성된 객체라도 메모리 공간이 완전히 분리되어 작동함 (`account_a is account_b` ➔ `False`).

### 이슈: 리브레오피스/엑셀에서 한글 깨짐 현상 (`µ¿È...`)
* **원인:** 한국어(`EUC-KR`/`CP949`)로 저장된 파일이 서유럽 문자(`ISO-8859-1`)로 잘못 해석되어 깨짐(Mojibake) 발생.
