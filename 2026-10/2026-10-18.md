## 2. 내가 궁금했던 질문과 이해한 답

### "−26bp면 비용을 조금 못 넘은 것 아닌가?"

수수료율 $f$(편도), 매도세율 $t$, 비용 전 총수익 $g$일 때 1주 기준 순수익은 선형이다.

$$\text{net} = g(1 - f - t) - (2f + t)$$

결과 요약 문서에 따르면 최고 규칙의 순수익 −25.6bp는 총수익 약 −2.6bp에 해당한다. 즉 **비용을 빼기 전에도 이미 손실**이다. "조금 부족"이 아니라 이 진입들에는 비용 전 우위가 없다는 뜻이고, 청산 규칙을 바꿔 메울 수 있는 거리(약 26bp)가 아니다. 그래서 다음 연구 순서를 "진입 신호의 비용 전 우위(gross edge) 확인 → 청산"으로 바꿨다.

아래는 이 식을 확인하려고 AI가 정리한 예시 코드다(프로젝트 코드 아님). 세율은 예시로 코스닥 0.20%를 넣었다.

```python
def breakeven_gross(f, t):
    return (2 * f + t) / (1 - f - t)

def gross_from_net(net, f, t):
    return (net + 2 * f + t) / (1 - f - t)

f, t = 0.00015, 0.0020
print(breakeven_gross(f, t) * 1e4)            # 약 23.05 bp
print(gross_from_net(-0.00256, f, t) * 1e4)   # 약 -2.6 bp
```

### LODO와 PBO가 "안정적"이면 좋은 신호인가?

- 하루씩 빼고 최고 규칙을 다시 고르면 10번 중 8번 같은 규칙이 뽑혔고, CSCV PBO는 0.33이었다. 순위는 어느 정도 유지된다.
- 하지만 **모든 순위가 음수 영역 안의 순위**다. 과최적이 덜하다는 것과 수익성이 있다는 것은 별개다.
- 특이일 하나(장중 시장 전체 체결 공백이 있던 날)를 뺀 회차는 600초 보유 규칙을 골랐는데, 그 규칙은 바로 그날 −120bp대였다. 긴 보유 규칙은 하루짜리 충격에 크게 흔들린다(그날 원인은 계약 밖이라 분석하지 않음 — 미확인).

## 3. 문제 → 해결 (실행 환경)

### pilot은 통과했는데 본 실행이 메모리 상한에서 멈췄다

- **문제:** 급등 연구의 pilot은 1일·100그룹으로만 쟀다. 본 실행에서 5일치 격자를 한 프로세스에 합치는 단계(약 143만 행)가 프로세스당 2GiB 상한을 넘어 멈췄다. pilot이 재지 않은 단계(정지 판정·경로·VI)도 날짜당 1.5~2시간씩 걸려 보고가 하루 밀렸다.
- **해결:** 결과를 만들거나 열람하지 않은 STOP 상태에서, 같은 run-root를 4GiB 상한으로 재개하고 일탈을 진행 기록에 남겼다(부모 프로세스 최대 약 2.5GiB).
- **규칙화:** 연구 상시 규칙에 "pilot은 본 실행의 모든 단계 시간·메모리를 잰다", "여러 날짜를 합치는 단계는 본 실행과 같은 크기(개발일 또는 합성 입력)로 최대 메모리를 재고, 상한의 70%를 넘으면 필요한 열만 읽기·날짜별 사전 요약으로 고친다"를 추가했다.

### 동결 계약 경로의 역슬래시 하나

- **문제:** 청산 탐색 계약의 공유 폴더 UNC 경로에서 역슬래시 하나가 빠져 있었다. 합성 테스트는 임시 폴더를 써서 잡지 못했다. 또 Git Bash는 `\\host` 인자의 역슬래시를 하나 지운다.
- **해결:** 실행 전 점검에서 발견해 첫 실행표를 무효로 하고, 경로만 고친 계약을 다시 동결했다(코드·manifest 동일 대조). 본 실행은 PowerShell로 띄웠다.

### 확인일과 개발일의 시간 창 맞추기

- 확인일은 08:00부터, 개발일은 09:00부터 데이터가 있어 그대로 넣으면 진입 판정 상태가 달라진다. 확인일을 개발일과 같은 창으로 자르는 래퍼를 만들고, 개발일에는 결과가 바뀌지 않음(no-op)을 증명한 뒤 썼다.

## 4. 배운 점

- 사전등록의 실제 효과는 "후보 없음"을 그대로 받아들이게 하는 것이었다. 관문·날짜·마감을 미리 묶어 두어 결과를 본 뒤 기준을 바꿀 여지가 없었다.

- 작은 pilot은 시간·메모리 양쪽에서 거짓 안심을 줄 수 있다. 합치는 단계는 실제 크기로 잰다.
