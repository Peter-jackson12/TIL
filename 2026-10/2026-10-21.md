## 1. 오늘 수업: 1장 3강 선형 변환과 신경망 레이어

학습 목표는 선형 변환과 행렬곱의 관계, 선형·아핀 변환의 차이, 가중치·편향의 역할, 레이어 출력 계산, 순전파 흐름이다.

- **선형 변환** `T(x) = xW`(행 벡터 기준). 덧셈 보존과 스칼라 곱 보존을 만족하며, 그 결과 `T(0)=0`이다.
- **아핀 변환** `f(x) = xW + b`. `f(0)=b`라서 편향이 0이 아니면 선형 변환이 아니다. 예: x=[3,2], W=diag(2,3), b=[1,-2] → xW=[6,6] → [7,4].
- **가중치**는 각 특성의 기여 정도와 방향(양수·음수·0)을 조절한다. 가중치 크기만으로 특성 중요도를 단정할 수 없고(스케일 차이), 음수 가중치가 인과를 뜻하지도 않는다.
- **편향**은 입력과 무관하게 더해지는 출력의 기준점(선형회귀의 절편과 같은 역할)이다. 편향만 바꾸면 모든 샘플이 같은 값만큼 이동하고, 가중치를 바꾸면 샘플별 변화량이 다르다.
- **다중 출력** `Z = X @ W + b`: X `(4,2)`, W `(2,3)`, b `(3,)` → Z `(4,3)`. b는 브로드캐스팅되고 파라미터는 6+3=9개다. 학습은 입력이 아니라 파라미터(W, b)를 조정하는 과정이다.
- **뉴런** `z = Σxᵢwᵢ + b` 뒤에 `a = f(z)`. ReLU는 `max(0, z)`이고 NumPy로는 `np.maximum(0, z)`.
- **활성화 함수가 필요한 이유:** 아핀 변환만 쌓으면 `y = x(W₁W₂) + (b₁W₂ + b₂)`로 하나의 아핀 변환과 같아진다. 비선형 활성화를 끼우면 일반적으로 그렇지 않다.
- **레이어 Shape:** X `(n_samples, n_inputs)`, W `(n_inputs, n_neurons)`, b `(n_neurons,)`, 출력 `(n_samples, n_neurons)`.
- **순전파 예제**(입력 2 → 은닉 뉴런 2개 + ReLU → 출력 1개, 활성화 없음): H = [[3,0],[5,3],[0,3]], 최종 Y = [[7],[8],[-2]], shape `(3,1)`. 출력 점수는 확률이 아니다. 순전파만으로는 학습이 되지 않고 손실 함수·역전파·경사하강법은 이후 강의에서 이어진다.
- 연습문제 1~3은 문제만 확인했고 접힌 답안은 확인하지 못했다. 입력 4·출력 3 레이어는 W `(4,3)`, b `(3,)`, 파라미터 15개다(직접 계산).
- 코딩테스트 연습: 다중 시작점 BFS(서버 모델 배포 최소 시간). `deque`·`visited`를 쓰고 starts 전부를 시간 0으로 큐에 넣는다. 도달 불가면 -1, 전부 보유하면 0. 풀이 제출 여부는 미확인.
- 강의 페이지 오타 메모: "전달할 수 없다면 **1**을 반환"은 -1의 오타(예시·본문은 -1). 순전파 설명의 "가중합은 1이었습니다"는 앞 예시의 z=7과 맞지 않는다.

## 2. 오늘 수업: 2장 1강 회귀와 분류 모델의 예측

학습 목표는 회귀·분류 차이, 이진·다중 클래스 분류, Sigmoid·Softmax 원리, Threshold·Argmax로 최종 클래스를 정하는 방법이다.

| 문제 유형 | 점수 | 확률 변환 | 최종 결정 |
|---|---|---|---|
| 회귀 | `xw+b` | 불필요 | 예측값 그대로 |
| 이진 분류 | Logit 1개 | Sigmoid | Threshold |
| 다중 클래스 | 클래스별 Logit | Softmax | Argmax |

- **회귀:** x=[4,2], w=[1000,3000], b=5000 → 15,000원(실제 12,000이면 오차 3,000). 단순 선형 회귀는 출력 범위를 제한하지 않아 음수 예측도 가능하다.
- **Logit은 확률이 아니다.** z=0.8이어도 구매 확률 80%가 아니다. 결과 Shape는 회귀·이진 분류 `(3,)`, 3클래스 `(3,3)`(행=데이터, 열=클래스).
- **Sigmoid** `1/(1+e^(-z))`: z=0→0.5, 2→0.881, -2→0.119. 출력은 0과 1 사이이고 정확히 0이나 1은 되지 않는다. z=0.8 → 0.69, 미구매는 `1-p`=0.31. 모델 확률이 실제 빈도와 맞는지는 별도 검증(Calibration)이 필요하다.
- **Softmax** `e^zᵢ / Σe^zⱼ`: [2,1,0] → [0.665, 0.245, 0.090], 합 1. `z - np.max(z)`로 오버플로를 줄이며, 모든 점수에 같은 상수를 더하거나 빼도 결과는 같다. 여러 데이터는 `axis=1, keepdims=True`로 행마다 계산한다.
- Sigmoid는 이진 분류·다중 레이블에, Softmax는 서로 배타적인 클래스 중 하나를 고르는 문제에 쓴다.
- **Threshold:** `p >= t`이면 1, 기본 0.5지만 고정값이 아니다. 올리면 양성 예측이 줄고 내리면 늘며, 올린다고 더 정확해지진 않는다. 코드는 `(p >= t).astype(int)`. 확률 출력을 고정하고 임계값을 올리면 FP는 감소·유지, FN은 증가·유지다. Sigmoid(0)=0.5이므로 임계값 0.5일 때만 `z >= 0`과 같은 결과다.
- **Argmax**는 최댓값이 아니라 인덱스를 반환하고, 동점이면 먼저 나온 인덱스를 반환한다. `axis=1`로 행마다 적용한다. `Argmax(z) = Argmax(Softmax(z))`라서 클래스만 정할 땐 Logit에 바로 써도 된다. 최고 확률 클래스가 정답이라는 보장은 없다(예: [0.36, 0.34, 0.30]).
- 다음 강의는 Likelihood와 손실 함수이며, 1장 3강의 출력층 활성화 부분이 여기서 Sigmoid·Softmax로 이어진다.

### AI 설명(직접 실행한 결과가 아님, 강의 자료에 없는 보충)

- 은닉층은 입력층과 출력층 사이의 층 전체이며, 가중합(활성화 전 Z)과 활성화 후 출력 H를 모두 포함한다. "숨겨졌다"는 우리가 직접 주지도 정답을 붙이지도 않는 중간 계산이라는 뜻이고, 층 수와 뉴런 수는 설계자가 정하며 값도 출력해 볼 수 있다. 다음 층으로 넘어가는 것은 활성화 후 값 H다.
- ReLU는 단순하지만 입력 구간마다 다른 계산을 만들어 비선형성을 준다. 활성화 함수는 ReLU, Sigmoid, Tanh 등의 총칭이다.
- 선형을 피하는 것이 아니라, 선형만 쓰면 층을 쌓아도 한 층과 같아지고 표현 가능한 관계가 직선·평면으로 한정된다. 아핀 변환은 뼈대로 두고 그 사이에 비선형 꺾임을 넣는다. (XOR은 강의에 없는 참고 예시)
- 뉴런 = 선형 모델 + 활성화 함수. 신경망은 이를 병렬로 둔 레이어를 사이마다 비선형을 끼워 직렬로 합성한 구조이며, 뉴런 하나에 Sigmoid를 붙이면 로지스틱 회귀와 같은 꼴이다(분류 강의에서 다룰 내용).
- 용어는 같은 연산을 위치·역할별로 부르는 이름이며, 핵심은 Shape 맞추기와 "활성화가 없으면 한 층으로 합쳐진다"는 이유다.
