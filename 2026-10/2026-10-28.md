## 1. 오늘 배운 것

수업 자료(노션 페이지 3장 1강·2강)의 본문을 읽어 정리했다. 아래 계산과 코드 주석의 결과는 **강의 자료에 적힌 값**이며, 내가 직접 실행해 확인한 값이 아니다.

### 3장 1강: CNN의 구조와 원리

- **CNN이 이미지에 맞는 이유:** MLP는 28×28 이미지를 784개 입력으로 펼쳐 주변 픽셀의 위치 관계를 직접 활용하기 어렵다. CNN은 작은 영역(국소성)에 같은 Filter를 여러 위치에 적용(가중치 공유, Weight Sharing)한다.
- **Filter와 Feature Map:** Filter는 학습 가능한 가중치 배열이고, Feature Map은 Conv 결과다. 4×4 입력에 3×3 Filter(대각선 1)를 Stride 1, Padding 0으로 적용하면 `[[3, 0], [3, 3]]`이 된다. 여러 Filter를 쓰면 출력 채널이 그 수만큼 늘고, RGB 3×3 Filter 하나의 가중치는 3×3×3 = 27개다.
- **출력 크기 공식:** `floor((입력 + 2×Padding − Filter) / Stride) + 1`. 5×5 입력, 3×3 Filter 기준 (S1, P0)=3×3, (S2, P0)=2×2, (S1, P1)=5×5.
- **Pooling:** 영역을 대표값으로 요약해 H, W를 줄인다. Max는 최댓값, Average는 평균. 4×4 예시에서 Max `[[6,5],[7,9]]`, Avg `[[3.5,2.0],[2.5,6.0]]`. 학습 가중치가 없고, B(Batch)와 C(Channel)는 유지된다. 정보가 일부 사라지므로 필수는 아니며 Stride가 큰 Conv로 대체하기도 한다.
- **전체 구조와 Shape 흐름(28×28 흑백, 배치 4):** `(4,1,28,28)` → Conv `(4,4,28,28)` → Pool `(4,4,14,14)` → Conv `(4,8,14,14)` → Pool `(4,8,7,7)` → Flatten `(4,392)` → Linear `(4,10)`. 순서는 `(Batch, Channel, Height, Width)`.
- **Logit과 학습:** Logit은 클래스별 점수, Softmax는 합이 1인 확률, Argmax는 예측 클래스. `CrossEntropyLoss`에는 Softmax를 미리 적용하지 않고 Logit을 그대로 넣는다. CNN도 순전파 → 손실 → 역전파 → 업데이트로 학습하고 Filter 가중치도 학습 대상이다. (Conv 역전파 유도는 강의에서 다루지 않음)

### 3장 2강: RNN과 LSTM

- **순차 데이터:** 순서가 중요한 데이터(텍스트, 시계열, 음성). 강의 예시로 상품 A(10→20→30)와 상품 B(40→35→30)는 3일차 값이 같아도 이전 흐름이 달라 현재 값만으로는 구분되지 않는다.
- **RNN:** `hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + b)`. 모든 시점이 같은 `Wₓ, Wₕ, b`를 공유하므로 시퀀스가 길어져도 가중치 수가 늘지 않는다. 강의 손계산 예시(`x=[1,2,3]`, `Wₓ=Wₕ=0.5`, `b=0`, `h₀=0`)의 Hidden State는 0.462 → 0.843 → 0.958.
- **장기 의존성과 기울기 소실:** 시간축 역전파(BPTT)에서 작은 값이 반복해서 곱해지면 기울기가 작아진다(강의 예시: 0.5를 8번 곱하면 0.0039). 모든 RNN에서 반드시 발생하는 것은 아니다.
- **LSTM:** Hidden State 외에 Cell State를 두고 Gate(Sigmoid, 0~1)로 정보를 조절한다.
  - Forget Gate: 이전 정보를 얼마나 유지할지
  - Input Gate: 새 정보(후보, tanh)를 얼마나 반영할지
  - Output Gate: 현재 Hidden State로 얼마나 내보낼지, `h = Output × tanh(C)`
  - Cell State 갱신 예시: `0.9×0.8 + 0.2×0.5 = 0.82`
  - 장기 의존성을 **완화**할 뿐 완전히 해결하지 못하며, 항상 RNN보다 성능이 좋은 것도 아니다.
- **입출력 구조:** Many-to-One(감정 분류, 다음 날 판매량 예측)과 Many-to-Many(품사 분류, 다중 시점 예측). Transformer는 4장에서 다룬다(Attention으로 위치 간 관계를 병렬 계산).
- 강의 도입부에는 상승/하락 8개 시퀀스를 RNN과 LSTM으로 학습하는 `SequenceClassifier` 코드(`BCEWithLogitsLoss`, Adam lr 0.03, 300 epoch)가 있다. 해당 페이지에 실행 결과 값은 없었고 나는 이 코드를 실행하지 않았다.

### 코딩 테스트 연습: 완전탐색(좌석 소음 점수)

- 문제: `seats`(0=빈 좌석, 1=사용 중)에서 빈 좌석의 상하좌우 1의 개수를 소음 점수로 하고, 점수가 가장 낮은 좌석을 고른다. 동점이면 행, 열이 작은 쪽, 빈 좌석이 없으면 `[-1, -1]`.
- 강의가 제시한 풀이 방향: 이중 반복문으로 순회하며 범위 안인지 확인하고, 현재 점수가 **더 작을 때만** 갱신하면 같은 점수일 때 먼저 찾은(행·열이 작은) 좌석이 유지된다.
- 이 문제를 내가 직접 풀거나 제출한 기록은 이 대화에 없어 **미확인**이다.

## 2. 내가 궁금했던 질문과 이해한 답

아래 답은 AI(Claude)가 설명한 내용이며, 강의 본문에 없는 배경지식은 그렇게 표시한다.

**Q. Hidden State는 왜 쓰는가?**
- 시점 t에서 현재 입력만 보면 앞에서 무엇이 나왔는지 알 수 없다. 그래서 이전 시점의 계산 결과 `hₜ₋₁`를 함께 받아 "지금까지의 요약 메모"로 쓴다. 상품 A와 B처럼 현재 값이 같아도 흐름(증가·감소)을 구분하게 해 주고, "고양이가 강아지를 쫓아간다"와 "강아지가 고양이를 쫓아간다"처럼 순서에 따라 의미가 달라지는 문장도 구분하게 한다.
- 과거 입력을 전부 저장하는 대신 고정 크기 벡터(예: `hidden_size=8`)로 요약해 넘기기 때문에, 시퀀스가 길면 오래된 정보가 약해질 수 있다. 이것이 장기 의존성 문제와 LSTM으로 이어진다.
- Many-to-One에서는 마지막 시점의 Hidden State로 예측하고(`outputs[:, -1, :]`), Many-to-Many에서는 시점마다의 Hidden State로 예측한다.

**Q. 이 내용이 이미지 압축과도 연관이 있는가?**
- (강의 밖 배경지식) Pooling과 Stride가 큰 Conv는 해상도를 줄인다는 점에서 이미지 축소와 비슷하고, 요약된 값만으로는 원래 값을 복원할 수 없다는 점에서 손실 압축과 성질이 닮았다. Conv·Pooling으로 줄였다가 복원하도록 학습하는 Autoencoder 구조가 관련이 있다. JPEG은 사람이 설계한 고정 변환(DCT)을 쓰고 CNN Filter는 데이터로 학습한다는 차이가 있다.
- 분류용 CNN의 Pooling은 복원이 목적이 아니라 분류에 필요한 특징을 요약하는 것이다. 나는 이를 실험으로 확인하지 않았다.

**Q. 지금 배우는 내용을 내가 만드는 카카오톡 봇에 써먹을 수 있는가?**
- 저장소에는 카카오톡 봇 기록이 없어 봇의 기능을 알 수 없는 상태에서 조건부로만 답을 받았다. 사용자가 보낸 이미지를 분류하는 기능이라면 CNN 구조와 Shape 개념이 직접 해당되고, 텍스트 중심이면 Conv·Pooling을 직접 쓸 곳은 적다. 학습 흐름과 Logit·Softmax·`CrossEntropyLoss` 사용법은 메시지 의도 분류 같은 분류 모델에 공통으로 쓰인다.
- (강의 밖 배경지식) 문장 분류에 1D Convolution을 쓰는 방법도 있다. 봇의 구체적인 기능은 아직 정해 두지 않았고, 이후 알려 줄 예정이다.
