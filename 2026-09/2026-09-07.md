## 1. 문제 인식 (Problem Recognition)

### ① Python OOP 스코프와 메모리 수명주기(Lifecycle): `self.`의 물리적 본질
- **지역 변수의 휘발성:** 메서드(`def`) 내부에서 `self.` 없이 선언된 변수는 호출 스택(Call Stack) 프레임 종료 즉시 메모리에서 증발(Garbage Collection)하여, 동일 클래스 내 다른 메서드에서 접근 시 `NameError`를 발생시킴을 확인했다.
- **인스턴스 바인딩:** `self.변수명`은 힙(Heap) 메모리에 할당된 객체 고유의 네임스페이스 딕셔너리(`__dict__`)에 영속적으로 묶여 인스턴스가 소멸할 때까지 상태(State)를 유지한다.
- **모듈 설계와 오버엔지니어링 경계:** 코딩 테스트 수준의 단발성 스택(`EditHistory`) 문제에서 굳이 클래스 래퍼를 씌우는 것은 문법 훈련용일 뿐, 실무적 관점에서는 불필요한 추상화 오버헤드임을 규명했다.

### ② 분류 평가지표의 착시와 조화평균(F1)의 필연성
- **혼동행렬(Confusion Matrix) 거꾸로 읽기:** $TP, FP, FN, TN$은 뒷글자(모델의 주장, $P/N$)를 앞글자(채점 결과, $T/F$)로 검증하는 2단계 해독법으로 완벽히 직관화했다.
- **용어 번역의 실패:** Accuracy(전체 정답률), Precision(저격 적중률), Recall(범인 검거율)로 재정의하여 직관적 모호성을 해소했다.
- **Accuracy의 착시와 기상청 사건:** 맑은 날(거대한 $TN$)이 70% 이상인 불균형 데이터셋에서는 기상청 슈퍼컴을 끄고 1년 내내 "비 안 옴"만 출력해도 정확도는 89.5%가 나온다. 거저먹는 $TN$을 배제하고 $TP$에 집중하는 **재현율(Recall/POD)**과 **Threat Score(TS/CSI / IoU)**, **F1-Score**를 확인해야 모델의 민낯이 드러남을 수리적으로 정리했다.
- **조화평균(Harmonic Mean)의 응징력:** 산술평균은 한쪽이 0점이어도 50점을 주지만, 역수의 산술평균을 다시 역수한 조화평균 $F1 = 2 \times \frac{P \times R}{P + R} = \frac{2TP}{2TP + FP + FN}$은 작은 값에 강력한 페널티를 부여하여 불균형 모델을 가차 없이 응징한다.

### ③ ROC-AUC의 기하학적 본질: 확률 크기가 아닌 '줄세우기(Ranking)'
- **다이얼(Threshold) 스위핑:** 둔감한 1.0(0, 0)에서 극단적 0.0(1, 1)까지 기준선을 낮출 때의 궤적이 ROC 커브다. 완벽한 모델은 암 환자를 100% 잡을 때까지 정상인을 단 1명도 오진하지 않아 왼쪽 벽을 타고 $(0, 1)$ 천장을 찍는다.
- **천장 수평 이동 $(0, 1) \to (1, 1)$의 진실:** 완벽한 모델임에도 선이 오른쪽으로 이동하는 이유는 모델의 결함이 아니라, **사용자가 억지로 Threshold를 0.0까지 내려 모든 정상인을 1로 강제 판정(FPR $\to 1.0$)했기 때문**에 발생하는 수학적 종착지임을 규명했다.
- **AUC = 순위 분리 확률:** 두 모델의 예측 확률 절대치가 완전히 달라도 클래스 간 순서가 완벽히 역전 없이 분리되어 있다면 ROC-AUC는 둘 다 완벽한 만점($1.0$)을 출력한다.

### ④ CART 알고리즘의 동점(Tie-breaking) 난수 개입과 결정트리 회귀의 한계
- **불순도 감소량의 완벽한 동점:** 피처 간 단조 증가/감소 순위가 100% 일치할 경우(예: 면적과 역 거리의 완전 역상관), 어느 피처로 자르든 불순도(Gini/MSE) 감소량이 소수점까지 동일하여 알고리즘은 `random_state` 난수에 의존해 첫 분기 질문을 결정한다.
- **외삽 불가(Extrapolation Failure):** 결정트리 회귀는 리프 노드의 표본 평균(Step-wise constant)을 출력하므로, 학습 데이터의 최대 범위(예: 70평, 110만 원)를 벗어나는 200평 펜트하우스가 들어와도 과거 최댓값 이상을 절대 예측하지 못하는 본질적 결함을 확인했다.

### ⑤ 지니 중요도(Feature Importance)의 연속형 편향과 퀀트 유니버스 커팅
- **상관계수와 중요도의 역전:** `TotalCharges`는 선형 상관계수가 $-0.19$로 중하위권에 불과하지만, 랜덤 포레스트 중요도에서는 압도적 1위를 기록한다. 이는 상관계수가 놓치는 비선형 상호작용($\text{tenure} \times \text{Monthly}$)을 포착함과 동시에, 분할 후보점이 수천 개에 달하는 **연속형 변수(High-Cardinality)에 지니 중요도가 편향(과대평가)**되기 때문이다.
- **퀀트 유니버스 커팅과의 등가성:** 결정트리의 공간 도려내기(Hyper-rectangle partitioning)는 퀀트의 시총·거래대금·재무제표 컷오프 필터링과 완벽히 동일하며, 트리는 이를 수학적 최적 임계값으로 자동화하고 체급별 분기(Branching)를 수행하는 진화된 유니버스 생성기임을 도출했다.

## 2. 직접 코드 실험 (Direct Code Experiment)

### ① `precision_recall_curve` 벡터 연산을 통한 최고 F1-Score 임계값(Threshold) 자동 탐색
```python
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import precision_recall_curve, f1_score

# 로지스틱 회귀 예측 확률 기반 최적 Threshold 자동 탐색
# y_test: 실제 정답 (1,409행), y_prob: 이탈 확률 (Positive=1)
precisions, recalls, thresholds = precision_recall_curve(y_test, y_prob)

# 조화평균 벡터화 연산 (Zero-division 방지 epsilon 포함)
f1_scores = (2 * precisions * recalls) / (precisions + recalls + 1e-10)

best_idx = np.argmax(f1_scores)
best_threshold = thresholds[best_idx]
best_f1 = f1_scores[best_idx]

print(f"👑 최적 Threshold      : {best_threshold:.4f}")
print(f"최적 지점 F1-score     : {best_f1:.4f}")
print(f"그때의 Precision(적중률): {precisions[best_idx]:.4f}")
print(f"그때의 Recall (검거율) : {recalls[best_idx]:.4f}")

# 기본 0.5 임계값 대비 개선도 검증
pred_default = (y_prob >= 0.5).astype(int)
pred_optimal = (y_prob >= best_threshold).astype(int)
print(f"기본(0.5) F1-score    : {f1_score(y_test, pred_default):.4f}")
print(f"최적({best_threshold:.2f}) F1  : {f1_score(y_test, pred_optimal):.4f} (성과 대폭 개선)")
```

### ② 완전 동점(Tie) 환경에서 `random_state`에 따른 CART 첫 분기 역전 및 키메라 샘플 예측 분기
```python
import pandas as pd
from sklearn.tree import DecisionTreeRegressor, export_text

# 면적(오름차순)과 역 거리(내림차순)의 순위가 100% 일치하는 완전 대칭 데이터
data = pd.DataFrame({
    "area": [25, 30, 40, 50, 60, 70],
    "station_minutes": [15, 12, 10, 6, 5, 3],
    "rent": [45, 50, 65, 80, 95, 110]
})

X = data[["area", "station_minutes"]]
y = data["rent"]

# 키메라 샘플: 면적은 80만원짜리(50), 역 거리는 95만원짜리(5)를 혼합
new_house = pd.DataFrame({"area": [50], "station_minutes": [5]})

# 난수 시드에 따른 최상단 분기 피처 선택 대조
for seed in [42, 422]:
    model = DecisionTreeRegressor(max_depth=3, random_state=seed).fit(X, y)
    pred = model.predict(new_house)[0]
    first_split = export_text(model, feature_names=list(X.columns)).split('\n')[0]
    print(f"[Seed {seed:3d}] 첫 분기: {first_split:<25} -> 예측 월세: {pred:.1f}만원")
```
**실행 결과:**
```text
[Seed  42] 첫 분기: |--- area <= 45.00           -> 예측 월세: 80.0만원
[Seed 422] 첫 분기: |--- station_minutes <= 8.00  -> 예측 월세: 95.0만원
```

## 3. 트러블슈팅 및 해결 (Troubleshooting & Resolution)

### Issue 1: `DecisionTreeRegressor`에서 `random_state` 변경 시 예측값이 `80.0`과 `95.0`으로 갈리는 현상
* **원인:** 두 Feature(`area`, `station_minutes`)가 완벽한 역상관 관계를 가져, 어떤 변수로 자르든 불순도(MSE) 감소량이 $100.000\%$ 동일한 **수학적 완전 동점(Tie)** 상태에 놓임. Scikit-learn의 `BestSplitter`가 난수(`random_state`)로 동전을 던져 분기 순서를 결정했고, 테스트 샘플이 `area=50`(80만 원 행)과 `station=5`(95만 원 행)의 스펙을 교차 보유하고 있어 발생한 필연적 분기 왜곡임.
* **해결:** `export_text`로 트리의 첫 분기 노드를 역추적하여 난수 개입을 실증함. 실제 고차원 데이터에서는 완벽한 동점이 드물지만, 다중공선성이 극심한 피처가 존재할 때 트리가 난수에 의해 자의적인 규칙을 세울 수 있음을 확인하고 VIF 기반 피처 정제 필요성을 확립함.

### Issue 2: Matplotlib/Seaborn 윈도우 한글 및 마이너스 부호 깨짐
* **원인:** 윈도우 환경 기본 폰트인 `DejaVu Sans`에 한글 글꼴 및 ASCII 대시(-) 유니코드가 매핑되지 않아 축 레이블과 음수 부호가 네모(`□`)로 렌더링됨.
* **해결:** 시각화 파이프라인 상단에 `plt.rcParams['font.family'] = 'Malgun Gothic'` 및 `plt.rcParams['axes.unicode_minus'] = False`를 글로벌 바인딩하여 해결함. 코랩 환경 대응을 위해 `koreanize-matplotlib` 자동 임베딩 스니펫 구축.

### Issue 3: ROC 커브 완벽 모델($AUC=1.0$)에서 우측 수평선 $(0, 1) \to (1, 1)$ 발생에 대한 오해
* **의구심:** 최고의 모델이라면 $FPR=0$이어야 하므로 X축으로 절대 이동하지 않아야 하는 것이 아닌가 하는 의문 발생.
* **수리적 규명:** ROC 커브는 Threshold를 $1.0 \to 0.0$으로 내리는 전수 궤적임. 다이얼이 $0.0$이 되면 모델은 모든 샘플을 양성($1$)으로 강제 예측하므로 정의상 무조건 $(1, 1)$에 도달해야 함. 완벽한 모델은 암 환자를 100% 잡을 때까지 $FPR=0$을 유지하며 $(0, 1)$을 찍고 난 뒤, 사용자의 강제 다이얼 조작으로 인해 천장을 타고 우측 이동함을 증명함.

### Issue 4: AI 코딩 에이전트(Cline) 운용 시 LLM 유료 구독제의 쿼터 고갈 병목

## 4. 퀀트 & 통계학적 인사이트 (Key Takeaways)

### 1. 결정트리 공간 분할(Spatial Partitioning)과 퀀트 유니버스 필터링의 등가성
* 퀀트 매니저가 경험적으로 자르던 유니버스 필터링(예: $\text{시총} \ge 1,000\text{억} \land \text{부채비율} \le 150\%$)은 결정트리가 고차원 공간을 직사각형(Hyper-rectangle)으로 잘라내는 과정과 정확히 일치한다.
* 머신러닝 트리는 인간의 주관적 감을 배제하고, 목적함수(상폐율 최소화, 수익률 순도 극대화)의 **지니 불순도를 가장 극적으로 낮추는 최적의 분할 임계값(Threshold)**을 데이터 기반으로 도출하므로, 퀀트 시스템의 1단계 사전 필터(Pre-filter) 엔진으로 즉시 전용 가능하다.

### 2. 선형 지표(상관계수)의 맹점과 트리 피처 중요도의 거품(Bias)
* 선형 상관계수가 낮다고 해서 버린 변수(`TotalCharges`, $r = -0.19$)가 트리 기반 비선형 결합에서는 핵심 알파가 될 수 있다.
* 반대로, 고유값(Unique Values)이 수천 개에 달하는 연속형 변수는 노드 분할 시 후보 선택지가 많아 지니 계수 감소량이 수학적으로 과대평가(High-Cardinality Bias)된다. 따라서 퀀트 피처 엔지니어링 시 지니 중요도를 맹신하지 말고, Permutation Importance 및 SHAP Value로 실질적 영향력을 교차 검증해야 과적합을 방어할 수 있다.

### 3. F1-Score와 퀀트 리스크 관리(손익비)의 대칭성
* Precision(적중률, 헛다리 방지)과 Recall(검거율, 대형사고 방지)은 시소(Trade-off) 관계다.
* 퀀트 트레이딩에서 손절 폭이 크고 익절 폭이 작은 전략(손익비 불리)은 손실 거래를 극단적으로 피해야 하므로 **Precision(Threshold 상향)**에 무게를 두어야 하고, 
* 반대로 블랙스완 폭락 방어나 추세추종 전략은 헛발질 손절을 감수하더라도 폭락/대세 상승을 절대 놓치지 말아야 하므로 **Recall(Threshold 하향)**에 무게를 두어야 함을 확인했다.
