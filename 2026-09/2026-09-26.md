## 1. 오늘 배운 것

### 1.1 대규모 replay는 계산 완료보다 완료 조건을 먼저 정의해야 한다

Stock의 MWFD 연구에서 45개 종목 runtime probe를 거친 뒤 MWFD-04의 1,286-cell 전체 Fast 실행 경로를 만들었다.

장시간 실행에서는 단순히 프로세스가 끝났다는 사실보다 다음을 확인해야 했다.

- 재개 가능한 checkpoint가 올바른 입력과 묶여 있는가
- partial publish가 COMPLETE로 잘못 보이지 않는가
- 기존 COMPLETE artifact도 현재 validation gate를 다시 통과하는가
- Fast와 Exact의 accounting acceptance가 별도로 확인되는가
- result 내부 상태가 서로 모순되지 않는가
- 어떤 tick engine과 코드 revision으로 계산했는지 provenance가 남는가

이 때문에 finalization을 fail-closed 계약으로 강화하고 checkpoint digest와 기존 artifact drift를 다시 대조하도록 했다.

### 1.2 pipeline audit은 "테스트가 통과한다"보다 "무엇을 테스트하지 않는가"를 찾는 작업이다

전체 pipeline을 다시 훑으면서 정상 경로에서는 동작해도 장애·재개·부분 게시 조건에서 잘못된 상태를 남길 수 있는 부분을 찾았다.

특히 Fast/Exact accounting acceptance, tick engine provenance, combine checkpoint digest, 기존 COMPLETE artifact drift, Operator 미완료 작업, managed capture 조기 종료, feature store atomic publish와 KIS daemon 완료 판정을 보강했다.

happy path 테스트만으로는 운영 신뢰성을 보장할 수 없고 중간 실패 이후의 상태 수렴이 별도 계약이어야 한다는 점을 배웠다.

### 1.3 Career 검색 backend는 검색 결과와 출처 계약을 분리해야 한다

Career Agent에서는 검색 discovery 경로를 Tavily backend로 전환했다.

검색 엔진이 URL을 찾아주는 것과 해당 URL이 실제 qualification에 사용할 수 있는 source인 것은 다른 문제이므로 source provenance 계약은 별도로 유지했다.

Wanted는 공식 상세를 찾지 못한 경우에만 제한적으로 사용할 수 있는 aggregator fallback으로 두고 Wanted URL 형식, source job id 일치, 전체 source text, manual-only intake 조건을 강제했다. 다른 aggregator를 같은 규칙으로 자동 허용하지 않았다.

### 1.4 실행 중인 패키지 revision을 기록해야 재현 가능한 manifest가 된다

Career Agent는 checkout 경로와 실제 설치된 wheel의 코드 revision이 다를 수 있다.

그래서 manifest provenance가 단순히 현재 Git working tree를 읽는 대신 **실제로 실행 중인 package revision**을 기록하도록 보강했다.

## 2. 직접 확인된 것과 아직 하지 않은 것

### 확인된 것

- MWFD-04 1,286-cell 전체 실행 경로와 finalization/검증 계약이 추가됐다.
- pipeline audit에서 발견된 Fast/Exact accounting, checkpoint, provenance, Operator, feature publish 관련 항목이 보강됐다.
- Career 검색 backend가 Tavily로 전환됐다.
- Wanted-only aggregator fallback 출처 계약이 병합됐다.
- 실행 중 package revision을 manifest provenance에 기록하도록 Career Agent가 수정됐다.

### 아직 완료하지 않은 것

- MWFD-04의 결과만으로 실전 전략 적격성을 선언하지 않았다.
- Wanted fallback은 공식 source와 동급의 자동 신뢰 경로가 아니다.
- 검색 결과에 포함됐다는 사실만으로 지원 가능 공고로 승격하지 않는다.
