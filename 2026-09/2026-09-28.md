추석 연휴로 정규 수업은 없었다. 오늘은 전날 시작한 MWFD Stage E full replay를 완료하고 종료 시점 체결 가정을 검토했다. Collector에서는 실제 시장에서 KRX/NXT dual 수집을 끝까지 돌렸고 Career System은 여러 운영 진입점을 Career Hub로 통합했다.

## 1. 오늘 배운 것

### 1.1 대규모 replay는 계산 종료 후 최종 검증까지 끝나야 완료다

Stage E full Fast replay는 전날 13:58:28 KST에 시작해 오늘 04:40:23에 계산이 끝났고 05:13:37에 최종 검증까지 완료됐다.

최종 범위는 다음과 같다.

- **1,286 cells**
- **11,084,034 paths**
- worker=2
- 실패 0
- 재시도 0
- 누락·중복 0

계산 결과뿐 아니라 shard의 물리·논리 무결성, canonical/result/accounting/gate/key/factor, baseline·nesting, identification·ledger를 다시 확인했다.

### 1.2 종료 시점 quote가 존재해도 실제 체결 가능한 가격이라는 뜻은 아니다

Stage E 결과의 terminal quote를 다시 확인한 결과 162개 cell 모두 frozen cache의 마지막 quote와 ledger가 일치했다.

하지만 terminal T 기준 2초 이내 fresh bid는 **0/162**였다. quote age는 최소 2.074초, 중앙 4.000초, 최대 78.444초였다.

저장 데이터의 일관성은 확인됐지만 해당 bid를 장 종료 시점의 즉시 체결 가격으로 그대로 사용하는 것은 별도의 가정이 필요했다.

### 1.3 백테스트 체결 모델은 현실성을 높이되 목적보다 복잡해지면 안 된다

강제청산을 현실적으로 만들기 위해 exact-T 순서, 취소/late fill, 부분체결, 유동성 예산, oversell, 예약 중복과 경계 조건을 synthetic model로 검증했다.

focused synthetic 검증은 최종 **231 tests PASS**까지 확인했다.

다만 연구 목적이 1주 단위 후보 비교인 상황에서 주문장 전체를 지나치게 세밀하게 재현하는 것은 복잡도에 비해 얻는 이점이 작을 수 있다고 판단했다. 이후 경제성 분석에서는 현재 가격과 1초 뒤 가격 중 더 보수적인 쪽을 사용하는 단순한 매도 가정으로 정리하는 방향을 잡았다. 이는 실제 시장가 체결을 증명한 것이 아니라 연구용 보수적 가정이다.

### 1.4 실제 dual collector에서는 문자열 호환성 같은 작은 경계가 전체 수집을 막을 수 있다

KRX-only 복구 과정에서 Kiwoom callback의 `real_type` 한글 문자열이 깨져 필터에서 탈락하는 문제가 직접 원인으로 확인됐다.

지원하는 체결·호가 타입에 한정해 alias mapping을 적용한 뒤 실제 유입이 복구됐다.

이후 KRX+NXT dual collector를 실제 시장에서 다시 실행했고 20:00:30에 정상 종료했다.

- accepted = committed: **21,198,465건**
- KRX 비중복 코드: **20,728,797건**
- NXT `_NX`: **265,193건**
- 중복 base·거래소 미확정: **204,475건**
- pending 0
- drop 0
- collector/writer 오류 없음
- 종료 코드 0

다만 품질 계수 71,560건과 깨진 alias의 전체 범위는 별도 검토 대상으로 남겼다.

### 1.5 Career Hub는 여러 도구를 하나의 front door로 모으되 기존 안전 경계를 유지해야 한다

Career Agent에서는 read-only Career Hub를 추가한 뒤 단계적으로 확장했다.

- v0.6.0: read-only HTML front door
- v0.7.0: artifact index 연결
- v0.8.0: localhost `hub-serve`
- v0.9.0: Hub에서 Daily 실행, plan·confirmation·shared live lock 연결

최종적으로 Hub가 production front door가 되고 기존 Daily launcher는 retired 상태로 정리됐다.

이와 별도로 CJ올리브영은 검증된 intake 경로로 production ingest를 완료했고, 아이샵케어 qualification은 안정화했다. BigInsight는 필수 요구조건 근거가 부족한 항목을 유지해 BLOCK/hold로 관리했다.

## 2. 직접 확인된 것과 아직 하지 않은 것

### 확인된 것

- Stage E 1,286 cells / 11,084,034 paths 전체 replay와 최종 검증이 완료됐다.
- terminal ledger 일치 162/162, terminal T 기준 fresh bid 0/162를 확인했다.
- 강제청산 synthetic focused tests 231개가 통과했다.
- 실제 KRX+NXT dual session이 accepted=committed 21,198,465건, pending/drop 0으로 정상 종료됐다.
- Career Hub v0.9.0이 Daily 실행까지 포함한 production front door로 정리됐다.
- CJ올리브영 ingest, 아이샵케어 qualification, BigInsight hold 상태가 각각 분리됐다.

### 아직 완료하지 않은 것

- terminal quote가 실제 시장가 체결 가격임을 증명한 것은 아니다.
- 단순화한 매도 가격 가정은 연구 모델이며 실제 execution guarantee가 아니다.
- dual collector의 품질 계수 71,560건과 전체 alias 품질은 별도 검토가 남아 있다.
- Career의 ingest/qualification 상태는 실제 지원 제출을 의미하지 않는다.
