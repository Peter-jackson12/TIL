추석 연휴로 정규 수업은 없었다. 오늘은 Stock 연구의 Fast↔Exact parity를 확인하고 전체 replay 실행 계획을 동결했다. Collector에서는 KRX와 NXT를 함께 등록하는 dual venue 경로를 준비했고, Career System에서는 eligibility provenance와 Practical Fit을 routing과 분리해 검증했다.

## 1. 오늘 배운 것

### 1.1 빠른 구현을 신뢰하려면 대표 경로에서 Exact와 기계적으로 같아야 한다

MWFD Stage C에서는 Fast replay와 Exact replay를 같은 입력에 대해 직접 비교했다.

총 **351개 경로에서 불일치 0건**을 확인했다.

이 결과가 전략 수익성을 의미하는 것은 아니지만 이후 대규모 Fast replay를 실행할 때 해당 계약 범위에서는 Exact와 동일한 결과를 낸다는 근거가 됐다.

### 1.2 큰 계산은 실행 전에 plan을 freeze해야 한다

Stage D에서는 바로 전체 replay를 시작하지 않고 cell/path 식별, 병렬 실행과 재개, result/accounting 검증, shard/manifest 결속과 최종 verification 순서를 먼저 고정했다.

Stage D를 동결한 뒤 Stage E full Fast replay를 시작했다. 시작 시각은 13:58 KST였고 worker=2로 실행했다. 이 작업은 오늘 안에 끝나지 않아 다음 날까지 이어졌다.

### 1.3 dual venue 수집은 "등록 성공"과 "실데이터 검증"을 구분해야 한다

Collector에 `--also-nxt-codes` 경로를 추가해 KRX와 NXT 코드를 동시에 등록하는 구조를 만들었다.

휴장 상태에서 약 90초 smoke를 실행해 로그인, 종목 등록, graceful shutdown이 정상 동작하는 것을 확인했다.

하지만 휴장 smoke에서는 실제 체결·호가 callback, 장시간 안정성, venue 분류 정확도를 검증할 수 없으므로 실제 시장 PASS로 확대하지 않았다.

### 1.4 Career eligibility는 결과값뿐 아니라 provenance와 actionability를 같이 봐야 한다

Career Agent에서는 eligibility metadata를 versioned contract로 만들고 operator와 review routing에 provenance와 actionability를 표시하도록 했다.

기존 v1과 v2의 route order도 직접 비교해 기존 routing 의미가 의도치 않게 바뀌지 않는지 확인했다.

Practical Fit은 통근, 보상, 역할 현실성 같은 정보를 보조적으로 보여주되 **production routing을 직접 바꾸지 않는 shadow 정보**로 유지했다.

### 1.5 qualification은 자동 점수보다 근거 항목을 직접 확인해야 한다

BigInsight, CJ올리브영, 아이샵케어 같은 후보의 필수요건과 source를 다시 확인했다.

"관련 경험이 있다"는 넓은 표현 대신 실제 요구조건을 항목별로 쪼개 SUPPORTED / PARTIAL / PROJECT_ONLY / NOT_SUPPORTED처럼 근거 수준을 분리했다.

## 2. 직접 확인된 것과 아직 하지 않은 것

### 확인된 것

- MWFD Stage C: 351경로 Fast↔Exact parity, 불일치 0건.
- Stage D execution plan이 freeze됐다.
- Stage E full Fast replay가 worker=2로 시작됐다.
- KRX+NXT dual registration 휴장 smoke가 정상 종료됐다.
- Career eligibility provenance/actionability contract가 production 코드에 반영됐다.
- Practical Fit은 routing을 바꾸지 않는 shadow 경로로 구현됐다.

### 아직 완료하지 않은 것

- Stage E는 오늘 종료되지 않았다.
- dual collector는 실제 시장 callback과 장시간 안정성이 아직 미검증이었다.
- Practical Fit은 지원 추천이나 자동 routing 판정이 아니다.
- qualification 후보는 source와 필수요건 확인 전까지 자동 지원 대상으로 보지 않는다.

## 3. 오늘의 핵심 정리

오늘의 공통 주제는 **큰 실행 전에 신뢰 경계를 고정하는 것**이었다.
