## 1. 오늘 배운 것

### 1.1 모델은 이름보다 데이터 구조와 계산 방식으로 구분해야 한다

ML 1장 2강에서는 Linear/Logistic Regression, Decision Tree, Random Forest, KNN, K-Means, PCA의 차이를 비교했다.

- Linear Regression은 연속값 예측의 기본선으로 볼 수 있다.
- Logistic Regression은 sigmoid를 이용해 분류 확률을 만든다.
- Decision Tree는 조건 분할로 규칙을 만들고, 깊어질수록 과적합 위험이 커진다.
- Random Forest는 여러 Tree를 bootstrap과 feature randomness로 묶어 단일 Tree의 불안정성을 줄인다.
- KNN은 가까운 K개 이웃을 이용하는 지도학습이다.
- K-Means는 target 없이 K개의 군집 중심을 찾는 비지도학습이다.
- PCA는 기존 feature를 조합한 새로운 축으로 데이터를 투영해 차원을 줄인다.

특히 KNN과 K-Means는 Euclidean distance 같은 거리 계산에 의존하므로 feature scale 차이가 결과를 지배할 수 있다. 반대로 Tree 계열은 값의 크기보다 분할 기준을 사용하므로 일반적으로 같은 이유의 scaling이 필요하지 않다.

KNN의 K는 **이웃 수**, K-Means의 K는 **군집 수**라는 점도 구분했다.

### 1.2 PCA는 단순히 feature 개수를 줄이는 기술이 아니라 분산을 보존하는 새 좌표계를 찾는 방법이다

PCA에서는 PC1이 데이터 분산을 가장 크게 설명하는 방향이고, 이후 주성분은 앞선 축과 직교하면서 남은 분산을 최대한 설명한다.

Explained Variance Ratio를 합해 몇 개의 주성분으로 원래 정보의 어느 정도를 보존하는지 판단할 수 있다.

Stock 프로젝트에는 PCA를 아직 정식 적용하지 않았다. 따라서 PCA를 이미 사용한 결과처럼 기록하지 않고, 원본 feature로 모델을 비교한 뒤 feature 수와 상관구조가 문제가 될 때 실험할 수 있는 후보로 남겼다.

### 1.3 시계열의 residual은 회귀의 잔차와 같은 "설명되지 않은 부분"이다

시계열 2장 1강에서는 시계열을 Trend, Seasonality, Residual로 나누는 관점을 공부했다.

additive decomposition의 기본 형태는 다음처럼 이해했다.

[
Y_t = Trend_t + Seasonal_t + Residual_t
]

여기서 residual은 추세와 계절성으로 설명한 뒤 남는 부분이다. 회귀에서 (y-hat y)를 잔차라고 부르는 것과 같은 기본 개념으로 연결했다.

분해 함수가 trend/seasonal/residual을 계산하더라도 사용자가 모든 것을 자동으로 맡기는 것은 아니다. 보통 주기 `period`와 additive/multiplicative 모델 같은 가정을 정해야 한다.

### 1.4 period는 임의 숫자로만 정하기보다 반복 구조를 먼저 확인할 수 있다

주기를 수학적으로 정할 수 있는지 질문하면서 ACF, FFT/periodogram 같은 방법으로 반복 주기 후보를 찾고, 후보 period로 분해한 뒤 residual에 구조적 자기상관이 남는지 비교하는 접근을 이해했다.

즉 "함수가 알아서 seasonality를 찾는다"기보다, **후보 주기를 데이터에서 찾고 분해 결과를 다시 진단하는 과정**이 필요하다.

주식 틱 데이터처럼 일정한 일주기 하나로 설명하기 어려운 데이터에서는 거래 시간대, 장 구간, 이벤트 구조를 먼저 생각해야 하므로 period를 기계적으로 하나 고정하기 어렵다는 점도 확인했다.

### 1.5 정상성은 시계열 모델링 전에 평균·분산·자기상관 구조가 시간에 따라 크게 바뀌는지 확인하는 문제다

정상성 진단에서는 ADF Test와 차분을 학습했다.

가격 수준 자체는 추세 때문에 비정상일 수 있고, 차분이나 수익률처럼 변화량으로 바꾸면 더 안정적인 구조가 나타날 수 있다.

현재 Stock 연구는 이벤트 기반 백테스트와 미세구조 분석이 중심이었고 ADF·차분·시계열 분해를 정식 연구 절차로 적용한 것은 아니다. 수업 내용은 이후 Stock 데이터의 시계열 EDA 후보로 연결하되, 실행하지 않은 분석 결과를 만들어 적지 않는다.

### 1.6 Stock 수집량 절감은 원본을 버리기보다 compact 파생 경로부터 검증해야 한다

Stock에서는 호가가 바뀔 때마다 모든 quote 이벤트를 영구 저장하는 대신, **체결이 발생한 시점의 최신 호가만 함께 저장하는 compact 방식**을 검토했다.

9/29 커밋에서는 다음 구조를 TODO로 문서화했다.

- quote callback은 계속 받되 종목/venue별 최신 호가를 메모리에 갱신한다.
- trade callback이 들어올 때 체결과 최신 quote snapshot만 영구 저장한다.
- `trade_timestamp`, `quote_timestamp`, `quote_age_ms`를 남겨 호가 신선도를 사후 검증한다.
- quote-only DB write를 줄이면 저장 용량, WAL, writer I/O를 줄일 가능성이 있다.

대신 체결 사이에 일어난 주문 추가·취소·잔량 변화가 사라지므로 exact order-book replay나 quote-only 미세구조 연구에는 사용할 수 없다.

따라서 기존 full raw를 바로 없애지 않고, 먼저 full raw에서 compact 파생 데이터를 만들어 용량 절감과 전략/feature 결과 차이를 비교하는 순서로 정리했다. **아직 collector 동작을 변경한 것은 아니다.**

### 1.8 Markdown Intake v1은 아이디어를 기록했지만 9/29에는 구현하지 않았다

채용사이트 API가 없어도 공고를 다룰 수 있도록 다음 흐름을 Career Agent ROADMAP에 추가했다.

## 2. 내가 궁금했던 질문과 이해한 답

### 왜 KNN/K-Means는 scaling이 중요하고 Tree는 덜 중요한가?

거리 기반 모델은 feature의 절대 크기가 거리 계산에 직접 들어가므로 단위가 큰 feature가 결과를 지배할 수 있다. Tree는 거리 대신 threshold 분할을 사용하므로 같은 문제의 영향을 덜 받는다.

### 시계열 residual도 그냥 잔차라고 부르는가?

그렇다. 회귀와 마찬가지로 모델이나 분해가 설명하지 못한 나머지를 뜻한다. 시계열에서는 remainder, error, resid 같은 표현도 함께 쓴다.

### decomposition의 period는 사용자가 임의로 넣어야 하는가?

최종 선택은 분석자가 해야 하지만 완전히 감으로만 고를 필요는 없다. ACF나 FFT/periodogram으로 반복 주기 후보를 찾고, 여러 후보의 residual 구조를 비교해 선택할 수 있다.

### PCA를 Stock에 바로 쓰는 것이 좋은가?

현재 Stock에서는 PCA를 적용한 적이 없다. 먼저 원본 feature로 모델과 데이터 구조를 이해하고, 차원 수·상관관계·계산량이 실제 문제가 될 때 비교 실험으로 도입하는 편이 해석하기 쉽다.
