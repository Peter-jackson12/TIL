## 1. 강의 자료 요약

### 1-1. 2장 2강: Likelihood와 Maximum Likelihood

학습 목표: 확률분포·조건부 확률과 모델 예측 확률의 연결, 확률과 우도의 차이, MLE의 원리, Log-Likelihood를 쓰는 이유, MLE와 손실 함수의 연결.

도입 예시: 고객 5명의 구매 여부 `y = [1, 0, 1, 1, 0]`(관측 구매 비율 3/5 = 0.6). 모델 A는 구매 확률 0.6, 모델 B는 0.8로 가정한다. 다음 강의의 MSE·Cross Entropy가 MLE와 어떻게 연결되는지 이해하기 위한 기초 강의다.

**① 확률분포와 조건부 확률**
- 확률변수 Y(구매=1, 미구매=0), `P(Y=1)=0.6`, `P(Y=0)=0.4`, 합은 1. 이산확률변수는 값마다 확률이 있고, 연속확률변수는 구간에 대한 확률을 확률밀도함수의 적분으로 구한다(밀도 값 자체는 확률이 아님). 이번 강의는 이산 분포 중심.
- 베르누이 분포: `P(Y=y) = p^y × (1-p)^(1-y)`, p가 파라미터. p=0.7이면 [미구매 0.3, 구매 0.7]. Sigmoid가 입력에 따라 p를 계산하는 데 쓰인다.
- 범주분포: 상호 배타적인 K개 클래스, `p₁+…+pₖ=1`. 예: 의류 0.6, 식품 0.3, 가전 0.1. Softmax가 범주분포의 확률 파라미터를 만든다.
- 조건부 확률 `P(B|A) = P(A∩B)/P(A)` (단 P(A)>0). 고객 10명 표(장바구니 추가 6명 중 구매 4 / 미추가 4명 중 구매 1): `P(구매)=0.5`, `P(구매|추가)≈0.667`, `P(구매|미추가)=0.25`. 상관이 인과를 뜻하지는 않는다.
- 조건의 방향: `P(구매|추가)=4/6≈0.667`, `P(추가|구매)=4/5=0.8`. 일반적으로 `P(B|A) ≠ P(A|B)`.
- NumPy: `np.mean(purchase[add_cart == 1] == 1)`처럼 조건으로 걸러낸 뒤 평균.
- 머신러닝: `P(Y=1 | X=x) = Sigmoid(x·w + b)`, 파라미터까지 쓰면 `P(Y=1 | X=x; θ)`. 입력이 다르면 예측 확률도 달라진다.
- 연습문제 1(문제만): 15명 표 → 구매 비율, p=0.7 베르누이 확률, `P(구매|추가)`, `P(추가|구매)` 비교, 3클래스 범주분포 해석. 예시 답안(펼쳐 확인): 구매 비율 8/15≈0.533, 0.7/0.3, `P(구매|추가)=6/8=0.75`, `P(추가|구매)=6/8=0.75`(이번엔 조건 집단 크기가 둘 다 8명이라 우연히 같음), 식품 확률 0.3.

**② Likelihood**
- 확률은 파라미터를 고정하고 "어떤 결과가 나올 가능성"을 묻고, 우도는 관측 데이터를 고정하고 "어떤 파라미터가 데이터를 더 잘 설명하나"를 비교한다. `L(θ|D) = P(D|θ)`. 우도가 파라미터가 참일 확률은 아니다(0.6이라고 60%가 아님).
- 한 관측: `L(p|y) = p^y (1-p)^(1-y)` → y=1이면 p, y=0이면 1-p.
- 여러 관측(독립 가정): `L(p|D) = ∏ p^yᵢ (1-p)^(1-yᵢ)`. 데이터 5명이면 `p³(1-p)²`. 이것은 순서가 정해진 관측의 우도이고, "구매자가 3명"이라는 개수만 관측한 사건의 확률은 이항계수가 추가로 곱해진다. 독립(조건부 독립) 가정을 쓴 것이다.
- 모델 A(p=0.6): `0.6³×0.4² = 0.03456`, 모델 B(p=0.8): `0.8³×0.2² = 0.02048` → A가 데이터를 더 그럴듯하게 설명. 단 우도가 크다고 새 고객 예측이 반드시 좋다는 보장은 없다.
- NumPy: `p ** y * (1-p) ** (1-y)` → `np.prod`.
- 입력에 따라 확률이 다른 경우(고객 3명, y=[1,0,1]): 모델 A 확률 [0.8,0.3,0.7] → 정답에 부여한 확률 [0.8,0.7,0.7] → 0.392, 모델 B [0.6,0.5,0.4] → 0.12. 정답 1이면 `pᵢ`, 정답 0이면 `1-pᵢ`를 쓴다. `pᵢ = Sigmoid(xᵢ·w+b)`, `θ=(w,b)`.
- 연습문제 2 예시 답안: p=0.7 → 0.147, p=0.5 → 0.125, p=0.9 → 0.081, 고객별 확률 모델 A 0.288 > B 0.240, 우도 0.4는 파라미터가 참일 확률 40%가 아님.

**③ MLE**
- `θ̂_MLE = argmax_θ L(θ|D)`. 앞에서 배운 `np.argmax`와 같은 원리(함수값이 가장 커지는 입력을 찾음)지만, 연속 파라미터에서는 배열 인덱스가 아니다.
- 베르누이 `L(p|D) = p^k (1-p)^(n-k)`, 후보 비교: p=0.2 → 0.00512, 0.4 → 0.02304, 0.6 → 0.03456, 0.8 → 0.02048. p를 키운다고 우도가 계속 늘지 않는 이유는 미구매 관측에 낮은 확률을 주기 때문.
- 동일한 p의 독립 베르누이 모델에서 `p̂_MLE = (y₁+…+yₙ)/n` = 관측 평균 = 0.6. 관측 비율을 쓰는 것이 편의가 아니라 우도 최대화 결과라는 점이 핵심. 미분으로 유도하는 것은 이후 강의로 미룸. 이 관계는 "모든 고객 확률이 동일"한 모델에만 해당한다.
- 격자 탐색: `np.linspace(0.01, 0.99, 99)`로 후보를 만들고 우도를 계산해 `np.argmax`. 파라미터가 많은 실제 모델에선 기울기 기반 최적화를 쓴다.
- 머신러닝에서는 학습할 대상이 p가 아니라 `w, b`다. 정답 1에는 높은 확률, 정답 0에는 낮은 확률을 주도록 조정한다. 파라미터를 조금 바꿔도 항상 우도가 오르는 것은 아니며 방향·크기는 최적화 방법이 정한다(경사하강법 강의에서 이어짐).
- MLE와 손실 함수: 우도 최대화 ↔ Log-Likelihood 최대화 ↔ NLL 최소화(같은 최적 파라미터). 우도에 단순 음수만 취하는 예(0.4 vs 0.2)도 보여 준다.
- 연습문제 3 예시 답안: y=[1,1,0,1] → `L = p³(1-p)`, p=0.5 → 0.0625, 0.75 → 0.105469, 0.9 → 0.0729, MLE=0.75, Sigmoid 모델이 추정하는 것은 `w, b`.

**④ Log-Likelihood와 NLL**
- 확률을 계속 곱하면 매우 작아진다(`0.5¹⁰⁰ ≈ 7.89×10⁻³¹`). 2000번 곱하면 `np.prod`는 0.0(언더플로)이고 `np.sum(np.log(...))`는 -1386.294.
- 로그: `a^b=c ↔ log_a(c)=b`, 자연로그 `ln`. 성질: `ln(ab)=ln a+ln b`, `ln(aⁿ)=n ln a`, 양수에서 단조 증가. 0~1 확률의 로그는 음수이며 1에 가까울수록 0.
- `ℓ(θ|D) = ln L(θ|D) = Σ ln P(yᵢ|θ)`. 베르누이: `ℓ = Σ[yᵢ ln p + (1-yᵢ) ln(1-p)]`.
- p=0.6: `3 ln0.6 + 2 ln0.4 ≈ -3.3651`, p=0.8: `≈ -3.8883`. 음수여도 값이 큰 쪽(-3.3651)이 더 좋다.
- `argmax L = argmax ℓ`이므로 MLE는 Log-Likelihood로 구해도 같다(격자 탐색 결과 0.6).
- 확률이 정확히 0이면 로그를 못 구하므로 작은 상수로 범위를 제한하거나 Logit에서 직접 손실을 안정적으로 계산하는 함수를 쓴다.
- `NLL(θ) = -ℓ(θ|D)`. 정답에 높은 확률(0.9) → `-ln 0.9 ≈ 0.105`, 낮은 확률(0.1) → `-ln 0.1 ≈ 2.303`. Total NLL과 Mean NLL은 고정 데이터셋에서 같은 최적 파라미터. 예: y=[1,0,1], p=[0.8,0.3,0.7] → 데이터별 [0.223, 0.357, 0.357], Total 0.936, Mean 0.312.
- 연결: 베르누이의 Mean NLL = Binary Cross Entropy(BCE)와 같은 형태, 범주분포의 NLL = Cross Entropy, 정규분포 가정의 MLE ↔ MSE(다음 강의).
- 연습문제 4 예시 답안: y=[1,0,1,0] → p=0.5의 우도 0.0625, 로그우도 ≈ -2.773, p=0.8은 ≈ -3.665, NLL 2.773 < 3.665, 정답 1에 0.9/0.1 부여 시 NLL 0.105/2.303, 로그를 쓰는 이유 두 가지(곱→합으로 계산·최적화 편리, 언더플로 방지; 단조 증가라 최적값 유지).
- 정리 표의 용어: 확률, 확률분포, 확률변수, 베르누이, 범주분포, 조건부 확률, 우도, MLE, 로그, Log-Likelihood, NLL, 언더플로.

**코딩테스트 연습: 이분 탐색(Binary Search)**
- 정렬된 `orders`에서 `queries`의 각 주문번호 인덱스를 찾고 없으면 -1. `left=0, right=len-1, mid=(left+right)//2`, `<`면 `left=mid+1`, `>`면 `right=mid-1`. 쿼리마다 범위를 새로 초기화. `list.index()`·`bisect` 금지. 풀이 제출 여부는 미확인.

### 1-2. 2장 3강: MSE와 Cross Entropy의 수학적 원리

학습 목표: 손실 함수의 역할, 정규분포 MLE와 MSE의 연결, 베르누이 NLL에서 BCE 도출, 범주분포 NLL에서 Categorical CE 도출, 손실값 해석. 열람 방법: 처음에는 Edge(Claude 확장)로 읽었으나 출력이 잘려 일부가 빠졌고, 이후 내부 브라우저로 다시 열어 빠진 부분과 연습문제 1~3 예시 답안(접힌 토글)을 채웠다. 마지막 코드 블록 일부(연습문제 3 답안의 Python 확인 코드 끝 등)는 보지 않았다. 이 페이지에는 코딩테스트 연습 섹션이 없었다.

**① MSE와 정규분포**
- 예측 문제의 세 형태: 구매 금액(실제 20,000/예측 18,000), 구매 여부(확률 0.8), 카테고리(의류 0.2, 식품 0.7, 가전 0.1). 회귀는 값의 차이로, 분류는 정답에 부여한 확률로 손실을 계산한다.
- 오차 `e = y - ŷ`. 평균하면 `-5`와 `5`가 상쇄되어 0이 되므로 제곱한다. 제곱오차 `(y-ŷ)²`는 부호가 사라지고 큰 오차를 더 크게 키우며, 예측이 맞으면 0.
- MSE = 제곱오차의 평균. 예: y=[10,20,30], 예측 [12,18,27] → 오차 [-2,2,3], 제곱오차 [4,4,9], MSE ≈ 5.667(모델 A). 모델 B는 예측 [9,24,33] → [1,16,9], MSE ≈ 8.667. 단위가 제곱이라 실제 금액 오차로 직접 해석하기 어렵고, 이상치의 영향을 크게 받아 MAE·RMSE도 함께 본다. `sklearn.metrics.mean_squared_error`로도 계산.
- 정규분포 `Y ~ N(μ, σ²)`: μ는 중심, σ²는 퍼짐. N(20,4)와 N(20,25)는 평균이 같고 분산(표준편차 2 vs 5)이 다르다. 연속 변수에서는 밀도 값 자체가 확률이 아니다.
- 가우시안 오차 가정: `Y | X=x, θ ~ N(ŷ, σ²)`, 즉 `y = ŷ + ε, ε ~ N(0, σ²)`. 모델의 예측값 ŷ가 조건부 정규분포의 평균이 된다. 모든 회귀 문제에서 성립하는 법칙이 아니라 MSE를 확률적으로 설명하기 위한 모델링 가정이라고 강의가 명시한다.
- 밀도 `f(y|x,θ) = 1/√(2πσ²) × exp(-(y-ŷ)²/(2σ²))`. 예: y=12, ŷ=10, σ=2 → ≈ 0.1210. 예측이 실제에 가까울수록 밀도가 높다.
- 평균 NLL(고정 σ) `= ½ln(2πσ²) + MSE/(2σ²)`. σ=2일 때 첫 항 ≈ 1.612, 모델 A: 1.612 + 5.667/8 ≈ 2.320, 모델 B: 1.612 + 8.667/8 ≈ 2.695. MSE가 작은 쪽이 NLL도 작다. 첫 항은 파라미터와 무관한 상수라 MSE 최소화와 NLL 최소화가 같은 최적 평균 파라미터를 고른다.
- 이 동치가 성립하는 조건: 오차가 독립, 평균 0 정규분포, 모든 데이터에 같은 고정 분산. 분산도 함께 학습하거나 데이터마다 다르면 NLL이 단순한 MSE와 같지 않다. 오차에 큰 이상치가 많으면 다른 손실·확률 모델을 고려할 수 있다.
- 정규분포 NLL 유도: `ln f = -½ln(2πσ²) - (y-ŷ)²/(2σ²)` → `NLL = ½ln(2πσ²) + (y-ŷ)²/(2σ²)`. 첫 항은 σ²만의 함수라 σ²를 고정하면 상수이고, 둘째 항이 제곱오차에 비례한다. n개 데이터는 `Total NLL = (n/2)ln(2πσ²) + 1/(2σ²)·Σ(yᵢ-ŷᵢ)²`, 평균은 `상수 + 양의 상수 × MSE`. 관계: 정규분포 우도 최대화 ↔ NLL 최소화 ↔ MSE 최소화.
- MSE를 쓰는 이유(강의 정리): ① 연속 수치의 오차를 평가 ② 큰 오차에 더 큰 손실(오차 2배 → 제곱오차 4배) ③ 정규분포 MLE와 연결 ④ 예측값에 대해 미분 가능해 경사하강법에 쓸 수 있다.
- 연습문제 1(y=[8,12,20], A=[10,11,18], B=[8,16,17]) 예시 답안: A 오차 [-2,1,2], 제곱오차 [4,1,4], MSE=3. B 오차 [0,-4,3], [0,16,9], MSE≈8.333, A 선택. σ=2 Mean NLL은 A ≈ 1.987, B ≈ 2.654. 오차 2→4는 제곱오차 4→16(2배 → 4배). 동치의 가정: 예측값이 조건부 정규분포의 평균, 오차 독립·정규, 모든 데이터 동일 분산(고정). Mean NLL = 상수 + 양의 상수 × MSE. (A·B의 MSE, Mean NLL, BCE, CE 평균 숫자는 NumPy로 재계산해 일치 확인.)

**② Binary Cross Entropy**
- 예: 실제 [1,0,1,0], 예측 확률 [0.9,0.2,0.6,0.7]. 정답에 높은 확률을 주면 손실이 작고, 낮은 확률을 주면 크다.
- 도출: 한 데이터의 `L(p|y) = p^y (1-p)^(1-y)` → 로그 `y ln p + (1-y) ln(1-p)` → 음수를 붙여 `BCE(y,p) = -[y ln p + (1-y) ln(1-p)]`. 베르누이 NLL과 같은 형태다.
- 정답 1이면 `-ln p`: p=0.9 → 0.105, 0.5 → 0.693, 0.1 → 2.303. 정답 0이면 `-ln(1-p)`: p=0.1 → 0.105, 0.5 → 0.693, 0.9 → 2.303.
- 틀린 예측에 확신이 높을수록 손실이 급증: 정답 1일 때 p=0.99 → 0.010, 0.01 → 4.605.
- Threshold 0.5에서는 0.9와 0.6이 모두 클래스 1이지만 BCE는 0.105 vs 0.511로 다르다. BCE는 클래스 정오가 아니라 정답에 준 확률까지 평가한다.
- 평균 BCE: 위 4명 데이터 → 데이터별 [0.105, 0.223, 0.511, 1.204], 평균 0.511. `sklearn.metrics.log_loss`가 평균 BCE. 확률이 정확히 0·1이면 로그 문제가 생겨 안정적인 구현을 쓴다.
- 모델 비교: 같은 4명에서 모델 B(예측 [0.9,0.2,0.8,0.1]) 평균 BCE ≈ 0.164 < 모델 A 0.511.
- Cross Entropy `H(q,p) = -Σ q(c) ln p(c)`로 보면 BCE는 정답 분포(원-핫)와 예측 베르누이 분포 사이의 Cross Entropy. 일반적 의미의 거리와 완전히 같은 개념은 아니다.
- MSE와의 대비(표는 일부만 확인): 분류에서도 MSE를 쓸 수는 있지만 베르누이 확률을 모델링하는 이진 분류에서는 BCE가 확률적 해석을 직접 준다.
- 학습 흐름: Logit `z = x·w + b` → `p = Sigmoid(z)` → BCE 계산 → BCE를 줄이도록 `w, b` 조정(경사하강법은 이후 강의). PyTorch `BCEWithLogitsLoss`는 Logit에서 안정적으로 계산한다. 손실 계산은 확률/Logit으로 하고 Threshold는 최종 클래스 결정에만 쓴다.

**③ Categorical Cross Entropy**
- 예: z=[2,1,0] → Softmax ≈ [0.665, 0.245, 0.090]. 세 상품이 모두 Argmax로 맞아도 손실은 정답 클래스에 준 확률에 따라 다르다.
- One-Hot: 실제 식품이면 `y=[0,1,0]`. 범주분포 Likelihood `P(Y=y|p) = p₀^y₀ p₁^y₁ p₂^y₂`, 예측 `p=[0.2,0.7,0.1]`이면 0.7.
- `CE = -Σ yᶜ ln pᶜ`에서 정답이 아닌 클래스 항은 0이 되어, 한 정답 클래스가 있을 때 `CE = -ln(정답 클래스의 예측 확률)`. 이 관계가 "매우 중요하다"고 강의가 강조한다.
- 식품이 정답일 때 세 모델: 식품 확률 0.7 → 0.357, 0.5 → 0.693, 0.1 → 2.303. A와 B는 Argmax가 같지만 CE가 다르다. C는 의류에 0.8을 주어 Argmax도 틀렸고 CE가 크다.
- NumPy: `y_prob[np.arange(len(y_true)), y_true]`로 정답 확률을 뽑고 `-np.log(...)`의 평균. y_true=[0,1,2], 확률 행렬 (3,3) → 정답 확률 [0.8, 0.6, 0.6]. Logit [[2,1,0],[0,2,1],[1,0,3]]에서 Softmax로 계산하면 데이터별 CE [0.408, 0.408, 0.170], 평균 CE 0.328(강의 출력값).
- 다중 클래스는 클래스가 서로 배타적일 때, 다중 레이블(한 이미지에 사람·자동차·나무)은 클래스별 독립 Sigmoid와 클래스별 BCE를 쓴다.
- 세 손실의 연결: 회귀 = 고정 분산 정규분포 → MSE(정규 NLL 최소화와 같은 최적 평균 파라미터), 이진 분류 = 베르누이 → BCE(NLL을 데이터 수로 나눈 값), 다중 클래스 = 범주분포 → CE(NLL을 데이터 수로 나눈 값). 이후 미분·최적화 강의에서 이 손실을 실제로 최소화하는 방법을 다룬다.
- MLE와 BCE/CE: `NLL(θ) = -Σ[yᵢ ln pᵢ + (1-yᵢ) ln(1-pᵢ)]`, 평균 BCE = NLL/n. 우도 최대화 ↔ NLL 최소화 ↔ BCE 최소화(같은 데이터셋·베르누이 모델 기준이며 정규화 항이 더해지면 최적화 문제가 달라질 수 있다). 범주분포도 `zᵢ = xᵢW + b`, `pᵢ = Softmax(zᵢ)`, `θ=(W,b)`, `Mean CE = NLL/n`. 다중 클래스 CE 평균 일반식 `-(1/n) ΣᵢΣₖ yᵢₖ ln pᵢₖ`.
- Likelihood와 CE 직접 비교: 정답 확률 [0.8,0.6,0.6] → 우도 0.288, `NLL=-ln(0.288)≈1.245`, 평균 CE = 1.245/3 ≈ 0.415.
- 원-핫을 쓰는 방식(`-np.sum(y_onehot*np.log(y_prob), axis=1)`)과 인덱스로 정답 확률을 뽑는 방식은 결과가 같고, 라이브러리가 인덱스를 요구하는지 원-핫을 요구하는지 확인해야 한다.
- 주의: PyTorch `CrossEntropyLoss`는 클래스 인덱스 정답과 Logit을 직접 입력받는다. 이미 Softmax를 적용한 확률을 다시 넣지 않도록 주의(이진 분류는 `BCEWithLogitsLoss`).
- BCE vs CE 비교표: 확률분포 베르누이/범주분포, 출력 함수 Sigmoid/Softmax, 모델 출력 클래스 1의 확률 하나/클래스별 확률, 정답 0·1 / 클래스 인덱스 또는 원-핫.
- BCE vs MSE 표: MSE는 회귀·연속 수치·차이 제곱·고정 분산 정규분포 NLL, BCE는 이진 분류·클래스 1 확률·정답 확률의 음의 로그·베르누이 NLL. 학습 데이터에서 손실이 작다는 것만으로 새 데이터 성능이 보장되지는 않아 검증 데이터 손실과 분류 성능도 함께 본다.
- 연습문제 2(y=[1,0,1], 확률 A=[0.8,0.3,0.9], B=[0.6,0.6,0.7]) 예시 답안: 고객 A `-ln0.8≈0.223`, 고객 B `-ln0.7≈0.357`, 모델 A 평균 BCE ≈ 0.228, 모델 B 데이터별 [0.511, 0.916, 0.357], 평균 ≈ 0.595, A가 더 좋음. Likelihood→BCE 도출 설명, 정답 1일 때 0.99 → 0.010, 0.01 → 4.605.
- 연습문제 3(분류) 예시 답안: 식품 원-핫 `[0,1,0]`, 모델 A(식품 0.8) CE 0.223 < 모델 B(식품 0.5) 0.693, 평균 CE ≈ 0.415, 우도 0.288·NLL 1.245와의 관계, `[0.85,0.10,0.05]`이면 Argmax는 의류이지만 정답 식품의 확률 0.10으로 CE ≈ 2.303.
- 강의 페이지 오타 메모: 연습문제 2 예시 답안 3번의 "고객 A: ln(0.8) ≈ 0.223"은 `-ln(0.8)`의 부호 누락 표기(값은 맞음).

## 3. AI 설명 (직접 실행한 결과 아님, 강의 자료에 없는 보충)

- **어렵거나 중요한 부분(질문 1):** 계산보다 개념 구분이 헷갈리는 강의다. 가장 중요한 것은 ① 우도 최대화 ↔ 로그우도 최대화 ↔ NLL 최소화(같은 최적 파라미터)이며 베르누이의 평균 NLL이 BCE로 이어진다는 점, ② 우도는 "정답에 부여한 확률"을 곱해 계산한다는 점이다. 헷갈리기 쉬운 부분은 ① 확률과 우도의 차이(수식은 같고 고정하는 대상이 다름, 우도 0.4는 파라미터가 참일 확률 40%가 아님), ② 조건부 확률의 방향(`P(구매|추가)≠P(추가|구매)`, 연습문제 1 답안에서 둘이 같은 것은 조건 집단 크기가 우연히 같아서), ③ MLE=관측 평균은 모든 고객의 확률이 같다고 가정한 모델에서만 성립한다는 점, ④ 로그우도가 음수여도 값이 큰 쪽이 좋다는 점이다. 격자 탐색, 이항계수·독립 가정, 이분 탐색 코딩테스트는 비중이 작다.
- **로그가 더 우수한 해를 주는가(질문 2):** 아니다. 로그는 단조 증가라 최적 파라미터가 변하지 않고(강의 예시에서 우도와 로그우도 모두 최적 p=0.6), 음수를 붙여 최소화로 바꿔도 같은 지점을 가리킨다. 로그를 쓰는 이유는 해가 아니라 계산 편의다. ① 언더플로 방지(확률 2,000개의 곱은 `np.prod`로 0.0이지만 로그의 합은 -1386.294), ② 곱셈이 덧셈이 되어 데이터별 손실을 더하고 평균 내는 구조가 됨, ③ 경사하강법이 "손실 최소화" 형태라 음수를 붙여 맞춤. 로그를 쓰면 기울기의 모양이 달라지기도 한다(9월 4일 TIL의 MSE 기울기 소실 대 BCE `(ŷ-y)x`)는 이야기는 "최적이 어디인가"가 아니라 "최적에 얼마나 잘 도달하는가"의 문제이며 이번 강의 범위 밖이고 이후 미분·최적화 강의에서 다룰 가능성이 있다.
- **`np.prod`(질문 3):** 배열의 모든 원소를 곱하는 함수(product)이며 `np.sum`의 곱셈 버전이다. `np.prod([2,3,4])=24`. 수식의 `∏`가 코드의 `np.prod`, `Σ`가 `np.sum`에 대응한다. 이 강의에서는 고객별 "정답에 부여한 확률"을 곱해 우도를 만든다(0.6×0.4×0.6×0.6×0.4=0.03456). `axis`를 주면 행·열 방향으로 따로 계산할 수 있다.
- **-1386.294(질문 4):** 맞다. `np.sum(np.log(np.full(2000, 0.5)))`은 `2000×ln0.5≈-1386.294`이며 이것이 로그우도 ℓ이다. 우도 `0.5²⁰⁰⁰`은 컴퓨터가 0.0으로 처리하고, 음수를 붙인 1386.294가 NLL이다. 로그우도가 음수인 것은 0~1 확률의 ln이 음수이기 때문이고, 0에 가까울수록 좋다. 이 값은 정답 확률이 모두 0.5인 모델의 점수다. `ln(L)`의 정의와 같은 값을, `L`을 직접 계산할 수 없어 로그를 먼저 취해 더하는 방식으로 구한 것이다.
- **NLL과 최소화(질문 5):** 맞다. `NLL = -(로그우도)`이고 부호를 뒤집었으므로 작을수록 좋다. 강의 예시 모델 A(p=0.6): 로그우도 -3.365 → NLL 3.365, 모델 B(p=0.8): -3.888 → 3.888로 A가 더 좋다. 학습에서는 이 NLL(BCE, CE)을 줄이도록 `w, b`를 조정한다. 강의는 NLL을 데이터 개수로 나눈 평균 NLL을 손실로 많이 쓰며, 평균을 내도 최적 파라미터는 같다.
- **분포별 범위(질문 6):** 2장 1강은 Sigmoid(이진)·Softmax(다중)·회귀를 모두 다뤘으므로 베르누이만 다룬 것이 아니다. 2장 2강은 확률분포 파트에서 베르누이와 범주분포를 소개했고, 우도·MLE·로그우도의 계산 예시는 베르누이(구매/미구매)로만 했다. 2장 3강에서 같은 "우도 → 로그우도 → NLL" 틀을 분포만 바꿔 세 번 적용한다: 회귀=정규분포→MSE(고정 분산 가정), 이진 분류=베르누이→BCE, 다중 클래스=범주분포→Categorical CE.
- **MLE에서 손실 함수로의 연결(질문 7):** `argmax L` → (로그) `argmax ℓ` → (음수) `argmin NLL`로 부호를 뒤집는 단계가 연결점이다. 강의에서는 2장 2강 끝의 "MLE와 손실 함수의 관계"가 개념 소개이고, 2장 3강에서 실제 식으로 보인다: 베르누이 NLL이 `-[y ln p + (1-y) ln(1-p)]`이면 BCE, 범주분포 NLL `-Σ yₖ ln pₖ`가 Categorical CE, 정규분포 NLL에서 상수를 빼면 제곱오차라 MSE. 손실 함수가 따로 있는 것이 아니라 MLE의 목적함수를 뒤집은 것이라는 점이 핵심이다.
- **BCE와 NLL의 차이(질문 8):** 수학적으로 거의 같다. NLL은 분포에 상관없이 쓰는 일반 개념(-로그우도)이고, BCE는 이진 분류(베르누이) 전용 이름이며 보통 평균을 낸 값이다. `NLL = -Σ[yᵢ ln pᵢ + (1-yᵢ) ln(1-pᵢ)]`(합산), `BCE = NLL / n`. 강의 예시 y=[1,0,1], p=[0.8,0.3,0.7]은 데이터별 [0.223, 0.357, 0.357], Total NLL 0.936, Mean NLL=BCE 0.312. n으로 나눠도 최적 파라미터는 바뀌지 않으며 평균을 쓰면 데이터 개수와 무관하게 크기를 비교하기 쉽다. 라이브러리에 따라 BCE가 합산을 반환하는 설정도 있다(이 강의 맥락에서는 평균 NLL).
- **예전 TIL의 BCE(질문 9):** [2026-09-04](./2026-09-04.md)의 ③("선형 점수(Logit) ➔ 확률(Sigmoid/Softmax) ➔ 벌점(BCE/CE)")와 ②의 기울기 소실 비교 실행 결과(MSE 기울기 -0.000200, BCE 기울기 -1.999800)에 있다. 9월은 "왜 MSE를 퇴출하고 CE를 쓰나(기울기·벌점)", 오늘은 "BCE가 우도에서 어떻게 나오나(MLE 유도)"로 같은 BCE를 다른 쪽에서 본 것이다. 9월 TIL에서 베르누이 NLL=BCE 유도는 검색에서 확인되지 않았다. 10월 21일 TIL에는 언급만 한 번 있다.
- **분류에 MSE를 쓰면 기울기가 소실되는 과정(질문 10):** 구조는 `z = w·x + b → p = Sigmoid(z) → 손실`이고 파라미터는 `w ← w − 학습률 × 기울기`로 갱신되므로 기울기가 0에 가까우면 학습이 멈춘 것처럼 된다. 정답 y=1 한 개 기준으로, MSE는 `L=(p−y)²`, `dL/dz = 2(p−y)·p(1−p)`로 Sigmoid 미분 `σ'(z)=p(1−p)`가 곱해진다. BCE는 `dL/dz = p − y`로, BCE의 `1/p`, `1/(1−p)`가 Sigmoid 미분 `p(1−p)`와 약분되어 사라진다(9월 4일 TIL의 "시그모이드 분모 상쇄").
  - 아래는 Claude가 NumPy로 직접 계산한 값이다(설명용 단일 샘플, 정답 1, `z`에 대한 기울기). 학습 실험이 아니라 일반화·실제 학습 속도와는 무관하다. z=0(p=0.5): MSE −0.25, BCE −0.5. z=−2(p=0.119): −0.185, −0.881. z=−4(p=0.018): −0.035, −0.982. z=−6(p=0.0025): −0.0049, −0.998. z=−8(p=0.0003): −0.0007, −0.9997.
  - MSE는 많이 틀릴수록 `p(1−p)≈0`이 되어 기울기가 사라지고(가장 틀린 곳에서 가장 약하게 고침), BCE는 틀릴수록 기울기가 −1에 가까워져 강하게 고친다. 손실값도 MSE는 최대 1에서 포화(0.9951 → 0.9993)하고 BCE는 `−ln p`로 6 → 8로 계속 커진다.
  - 예: 기울기 약 0.005일 때 학습률 0.01이면 한 번에 `z`가 약 0.00005만 움직여 사실상 제자리다. 실제 `w` 기울기는 여기에 입력 `x`가 곱해질 뿐이라 경향은 같지만, 여러 데이터가 섞인 전체 학습이 얼마나 느려지는지는 따로 실험하지 않았다. 9월 4일 TIL의 "비볼록 웅덩이" 표현은 이번 계산으로 확인하지 않았다.
- **BCE+Sigmoid가 항상 나은가(질문 11):** 분류에서는 대체로 BCE가 낫다고 보지만 "항상"은 아니다. 근거: ① 오답에 확신해도 기울기가 `p−y`로 강하게 고쳐진다(MSE는 `p(1−p)`로 약해짐), ② 베르누이 MLE에서 직접 유도된다(MSE는 정규분포 가정의 회귀 손실), ③ 확신하고 틀리면 `−ln p`가 계속 커지는 벌점(MSE는 1에서 포화). 항상은 아닌 경우(아래는 강의 자료에 없는 일반 지식이며 직접 실험한 결과가 아님): 최종 정확도만 보면 두 손실의 성능이 비슷할 수도 있고(데이터·모델마다 다름), Brier score는 이진 분류의 MSE로 확률 교정 평가에 쓰이며, Sigmoid 없이 Logit에 MSE를 쓰면 기울기 소실 문제의 전제가 달라지고, 라벨이 잘못 붙은 데이터에는 BCE의 큰 벌점이 학습을 끌고 갈 수 있다. 강의 자료는 "분류에 MSE를 쓸 수 없는 것은 아니지만 이진 분류에서는 BCE가 직접적인 확률적 해석을 준다"고만 말하며 항상 낫다고 주장하지 않는다.
