## 1. 강의 자료 요약

### 1-1. 1장 3강: 선형 변환과 신경망 레이어

학습 목표: 선형 변환과 행렬곱의 관계, 선형 변환과 아핀 변환의 차이, 가중치·편향의 역할, 레이어 출력 계산, 순전파 흐름.

- 선형 변환 `T(x) = xW`(행 벡터 기준, 열 벡터 표기는 `Wx`). 덧셈 보존 `T(a+b)=T(a)+T(b)`와 스칼라 곱 보존 `T(ca)=cT(a)`를 만족하며, 그 결과 `T(0)=0`이다.
- 아핀 변환 `f(x) = xW + b`. `f(0)=b`이므로 편향이 0이 아니면 선형 변환이 아니다. 예: x=[3,2], W=diag(2,3), b=[1,-2] → xW=[6,6] → [7,4].
- 가중치는 각 특성의 기여 정도와 방향(양수·음수·0)을 조절한다. 가중치 크기만으로 특성 중요도를 단정할 수 없고(스케일 차이), 음수 가중치가 인과를 뜻하지도 않는다.
- 편향은 입력과 무관하게 더해지는 출력의 기준점이며 선형회귀의 절편과 같은 역할이다. 편향만 바꾸면 모든 샘플이 같은 값만큼 이동하고, 가중치를 바꾸면 샘플별 변화량이 다르다.
- 다중 출력: `Z = X @ W + b`, X `(4,2)`, W `(2,3)`, b `(3,)` → Z `(4,3)`. b는 브로드캐스팅. 파라미터는 6+3=9개.
- 학습은 입력이 아니라 파라미터(W, b)를 조정하는 과정(예측 → 손실 → 조정 반복).
- 뉴런: `z = Σxᵢwᵢ + b`(아핀) 후 `a = f(z)`. ReLU는 `max(0, z)`, NumPy는 `np.maximum(0, z)`.
- 활성화 함수가 필요한 이유: 아핀 변환만 쌓으면 `y = x(W₁W₂) + (b₁W₂ + b₂)`로 하나의 아핀 변환과 같아진다. 비선형 활성화를 끼우면 일반적으로 그렇지 않다.
- 레이어 Shape: X `(n_samples, n_inputs)`, W `(n_inputs, n_neurons)`, b `(n_neurons,)`, 출력 `(n_samples, n_neurons)`.
- 순전파 예제(입력층 2 → 은닉층 뉴런 2, ReLU → 출력층 1, 활성화 없음): 은닉층 출력 H = [[3,0],[5,3],[0,3]], 최종 Y = [[7],[8],[-2]], shape `(3,1)`. 출력 점수는 확률이 아니다.
- 순전파만으로는 학습이 안 되고, 손실 함수 → 역전파 → 경사하강법이 이후 강의에서 이어진다.
- 연습문제 1~3: 문제만 확인했고 접힌 예시 답안은 확인하지 못했다. 입력 4·출력 3 레이어는 W `(4,3)`, b `(3,)`, 파라미터 15개(문제 2-5, 직접 계산).
- 코딩테스트 연습: 다중 시작점 BFS(서버 모델 배포 최소 시간). `deque`·`visited`, starts 전부를 시간 0으로 큐에 넣는다. 미도달이면 -1, 전부 보유하면 0. 풀이 제출 여부는 미확인.
- 강의 페이지 오타 메모: 제한사항·풀이 과정의 "전달할 수 없다면 **1**을 반환"은 -1의 오타(예시·본문은 -1). 순전파 설명 중 "앞서 계산한 뉴런의 가중합은 1이었습니다"는 앞 예시의 z=7과 맞지 않는다.

### 1-2. 2장 1강: 회귀와 분류 모델의 예측

학습 목표: 회귀·분류 차이, 이진·다중 클래스 분류, Sigmoid·Softmax 원리, Threshold·Argmax로 최종 클래스 결정.

| 문제 유형 | 점수 | 확률 변환 | 최종 결정 |
|---|---|---|---|
| 회귀 | `xw+b` | 불필요 | 예측값 그대로 |
| 이진 분류 | Logit 1개 | Sigmoid | Threshold |
| 다중 클래스 | 클래스별 Logit | Softmax | Argmax |

- 회귀 예: x=[4,2], w=[1000,3000], b=5000 → 15,000원(실제 12,000이면 오차 3,000). 단순 선형 회귀는 출력 범위를 제한하지 않아 음수 예측도 가능하다.
- Logit은 확률이 아니다. 예: z=0.8이어도 구매 확률 80%가 아니다. 결과 Shape는 회귀·이진 분류 `(3,)`, 3클래스 `(3,3)`(행=데이터, 열=클래스).
- Sigmoid `1/(1+e^(-z))`: z=0→0.5, 2→0.881, -2→0.119. 출력은 0과 1 사이이고 정확히 0이나 1은 되지 않는다. 예: z=0.8 → 0.69, 미구매는 `1-p`=0.31. 모델이 낸 확률이 실제 빈도와 맞는지는 별도 검증(Calibration)이 필요하다.
- Softmax `e^zᵢ / Σe^zⱼ`: [2,1,0] → [0.665, 0.245, 0.090], 합 1. `z - np.max(z)`로 수치 오버플로를 줄이며, 모든 점수에 같은 상수를 더하거나 빼도 결과는 같다. 여러 데이터는 `axis=1, keepdims=True`로 행마다 계산한다.
- Sigmoid는 이진 분류와 다중 레이블에, Softmax는 서로 배타적인 클래스 중 하나를 고르는 문제에 쓴다.
- Threshold: `p >= t`이면 1, 기본 0.5지만 고정값이 아니다. 올리면 양성 예측이 줄고 내리면 늘며, 올린다고 더 정확해지진 않는다. 코드는 `(p >= t).astype(int)`.
- 오분류: TP/TN/FP(음성을 양성으로)/FN(양성을 음성으로). 임계값을 올리면 FP는 감소·유지, FN은 증가·유지(확률 출력 고정 시).
- Sigmoid(0)=0.5이므로 Threshold 0.5일 때는 `z >= 0`만 봐도 같은 결과다. 다른 임계값에서는 성립하지 않는다.
- Argmax는 최댓값이 아니라 인덱스를 반환하고, 동점이면 먼저 나온 인덱스를 반환한다. `axis=1`로 행마다 적용한다. `Argmax(z) = Argmax(Softmax(z))`라서 클래스만 정할 땐 Logit에 바로 써도 된다.
- 최고 확률 클래스가 정답이라는 보장은 없다. 예: [0.36, 0.34, 0.30]은 의류가 뽑히지만 확신하기 어렵다.
- 다음 강의는 Likelihood와 손실 함수. 1장 3강에서 출력층에 활성화를 안 붙였던 부분이 여기서 Sigmoid·Softmax로 이어진다.
- 코딩테스트 연습은 이 페이지에 없었다(해당 강의 범위 밖).

### 1-3. 2장 1강 연습문제 예시 답안(노션 접힌 토글을 펼쳐 확인)

- 연습문제 1: ① 구매 금액=회귀, 구매 여부=이진 분류 ② 고객 A: 5×1000+1×2000+3000 = 10,000원 ③ 고객 B: 2×0.5+3×1.0−2 = 2, 구매 확률 200%를 뜻하지 않음 ④ 식품(0.6)이 가장 유력, 상호 배타적 3클래스라 다중 클래스 분류.

## 3. AI 설명 (직접 실행한 결과 아님, 강의 자료에 없는 보충)

- 은닉층은 입력층과 출력층 사이의 층 전체이며, 가중합(활성화 전 Z)과 활성화 후 출력 H를 모두 포함한다. "숨겨졌다"는 것은 우리가 직접 주지도 정답을 붙이지도 않는 중간 계산을 뜻하고, 층 개수와 뉴런 수는 설계자가 정하며 코드에서 값도 출력해 볼 수 있다. 다음 층으로 넘어가는 것은 활성화 후 값 H다.
- ReLU는 단순하지만 입력 구간마다 다른 계산을 만들어 비선형성을 준다. 활성화 함수는 이런 함수들(ReLU, Sigmoid, Tanh 등)의 총칭이다.
- 선형을 피하는 것이 아니라, 선형만 쓰면 층을 쌓아도 한 층과 같아지고 표현할 수 있는 관계가 직선·평면으로 한정된다. 아핀 변환은 뼈대로 유지하고 그 사이에 비선형 꺾임을 넣는다. (XOR은 강의에 없는 참고 예시)
- 뉴런 = 선형 모델 + 활성화 함수. 신경망은 선형 모델 여러 개를 병렬로 둔 레이어를 직렬로 합성하되 사이마다 비선형을 끼운 구조이며, 뉴런 하나에 Sigmoid를 붙이면 로지스틱 회귀와 같은 꼴이다(분류 강의에서 다룰 내용이라 참고).
- 용어는 같은 연산을 위치·역할별로 부르는 이름이며, 핵심은 Shape 맞추기와 "활성화가 없으면 한 층으로 합쳐진다"는 이유다.

질문 8~20에 대한 AI 설명:

- **Threshold·Argmax 생략 규칙(질문 8):** Sigmoid와 Softmax는 점수의 순서를 바꾸지 않는다. Sigmoid(0)=0.5라서 임계값 0.5일 때는 `z >= 0`만 봐도 같은 판정이고(다른 임계값에서는 성립하지 않음), Softmax 전후의 최댓값 위치가 같아서 클래스만 정할 때는 `np.argmax(z)`를 바로 써도 된다. 확률 값 자체가 필요하면 계산해야 한다. Argmax는 전체 순위나 점수 차이가 아니라 "가장 큰 값이 있는 칸의 번호" 하나만 돌려주고, 클래스 개수가 3개면 0~2 중 하나다.
- **`@`와 `np.matmul`(질문 10):** ndarray에서 `A @ B`는 `np.matmul`을 부르는 기호라 항상 같다. 1차원끼리는 내적(스칼라), 2차원끼리는 행렬곱이고, 행렬곱의 각 원소는 행과 열의 내적이다. `np.dot`은 1·2차원에서는 같지만 3차원 이상과 스칼라 곱에서 동작이 다르다.
- **LP와 머신러닝(질문 11):** LP(선형계획법)는 머신러닝의 직접 조상이라기보다 같은 최적화 가족이다. 직접 조상은 통계학(최소제곱·회귀)과 수치 최적화, 퍼셉트론에서 이어진 신경망 흐름이다. LP는 선형 목적함수와 선형 제약에서 꼭짓점을 따라 정확한 해를 찾고, 경사하강법은 기울기 반대 방향으로 조금씩 이동하는 근사 방법이다. 목적은 "손실 최소화"로 같지만 풀이 도구가 다르다. 9월 4일 TIL 제목의 "OLS vs GD vs LP"도 같은 문제를 다른 방식으로 푸는 비교다.
- **딥러닝의 난점(질문 12):** 순전파는 오늘 연습문제처럼 손으로 계산할 수 있는 행렬곱·덧셈·ReLU이고 역전파도 미분 공식이라 원리상 손으로 쓸 수 있다. 어려운 점은 계산 가능성이 아니라 해석 가능성이다(파라미터가 수백만~수십억 개이고 비선형이 합성되어 개별 가중치의 의미를 설명하기 어렵다). 랜덤 포레스트·부스팅 같은 ML 앙상블도 해석이 어렵다.
- **LLM과 어텐션(질문 13):** LLM은 대부분 트랜스포머 신경망이고, 행렬곱·Softmax 같은 오늘의 부품으로 구성된다. 단순화한 어텐션은 ① 내적으로 단어 사이 관련도 점수 ② Softmax로 합이 1인 참고 비율 ③ 그 비율로 정보를 가중합이다(실제 구현에는 Query/Key/Value 변환과 점수 크기 보정이 더 있다). 설명에 쓴 숫자는 가짜 값이다.
- **기초 수학의 위치(질문 14):** 1장 1~3강은 데이터·가중치 그릇, 계산 연산, 층 구조와 순전파이고 2장 1강은 출력을 확률·클래스로 바꾸는 단계다. 이후 손실 함수와 미분·최적화가 "학습" 부분을 채운다. 딥러닝 전용이라기보다 일반 ML과 공통인 토대다.
- **노드 그림과 학습(질문 15):** 노드는 값 하나, 선은 가중치 하나이고 한 열이 한 층이며, 선 얽힘 전체가 행렬곱 한 줄 `Z = X @ W + b`로 압축된다. 노드가 수십 개인 출력층은 클래스 수만큼의 Logit 노드이고 Softmax를 씌우면 정답 노드에 확률이 몰린 그림이 나온다. 학습은 ① 가중치를 작은 무작위 값으로 초기화 ② 순전파 ③ 정답과 비교해 손실 계산 ④ 손실이 줄도록 모든 층의 가중치를 조금씩 조정(역전파·경사하강법) ⑤ 반복이다. 정답을 외우게 하는 것이 아니라 여러 예시에 공통으로 통하는 가중치를 찾는 것이고, 새 데이터에서 틀리면 과적합이다.
- **ReLU의 위치(질문 16):** ReLU는 선형 계산 뒤에 결과를 자르므로 `z` 자체가 음수가 되는 것은 막지 않는다(강의 예제의 `z = [3, -3]`, 가중치 `-2`도 음수). 음수 z는 그 뉴런이 "꺼짐(0)"으로 다음 층에 전달되며, 계속 꺼져 있으면 학습에 참여하지 못하는 죽은 ReLU 문제가 생길 수 있다. 활성화 없는 출력층에서는 음수 출력이 그대로 나온다(순전파 예제의 `-2`).
- **구조 정리(질문 17~18):** 딥러닝은 (선형 변환 → 비선형 활성화)를 여러 층 쌓은 함수와 그 가중치를 손실 최소화로 학습하는 방법이다. 활성화는 ReLU만이 아니고 층마다 달라서, 보통 은닉층은 ReLU 계열, 출력층은 이진 분류 Sigmoid·다중 분류 Softmax·회귀는 없음이다. LSTM처럼 한 셀 안에서 Sigmoid와 Tanh를 함께 쓰는 구조도 있다. 은닉층은 입력층과 출력층 사이의 층들(선형 + 활성화)이고, 가중치와 편향은 출력층을 포함한 모든 층에 있으며 활성화 함수 자체에는 학습 파라미터가 없다. 활성화는 비선형이어야 의미가 있지만 학습이 잘 되는 성질(기울기가 너무 작아지지 않음, 계산이 단순함)을 보고 고른다.
- **학습되는 가중치(질문 19):** 은닉층과 출력층 가중치 전부를 동시에 조정한다. 손실은 출력과 정답으로 계산하지만 역전파가 오차를 뒤에서 앞으로 전달해 앞쪽 층 가중치가 얼마나 영향을 줬는지까지 계산한다. 입력 데이터 `X`와 활성화 함수는 학습으로 바뀌지 않는다.
- **9월 4일 TIL과의 관계(질문 20):** 시그모이드 관련 기록은 [2026-09-04](./2026-09-04.md)의 ③("선형 점수(Logit) ➔ 확률(Sigmoid/Softmax) ➔ 벌점(BCE/CE)")에 있고, 로짓의 정체, `σ'(z) = p(1-p)`, MSE의 기울기 소실과 BCE의 `(ŷ-y)x` 상쇄가 정리돼 있다. 오늘 2장 1강은 그 앞 단계로, Sigmoid·Softmax의 손계산, 평행이동 불변과 `z - np.max(z)`, `axis=1, keepdims=True`, Threshold·Argmax 규칙이 새로 나왔다고 AI가 비교했다. 9월 TIL은 "왜 이렇게 설계됐나", 오늘은 "정확히 어떻게 계산하나"에 가깝고, 손실 쪽은 다음 강의에서 다시 만난다. 어느 기록이 "깨달음"이었는지는 사용자가 확인하지 않았다.

### AI가 직접 실행한 신경망 학습 예시(가상 숫자, 일반화 성능과 무관)

질문 19에 답하려고 Claude가 NumPy로 직접 돌려 본 결과다. 가중치·정답은 설명용으로 임의로 정한 값이며 실제 데이터가 아니다.

- 구조: 입력(특성 2) → 은닉층1(뉴런 2, ReLU) → 은닉층2(뉴런 2, ReLU) → 출력(1, 활성화 없음). 고객 2명 `X = [[3,2],[1,4]]`, 정답 `[10, 8]`, `W1 = [[1,-2],[2,1]]`, `b1 = [-4,1]`, `W2 = [[1,2],[1,-1]]`, `b2 = [0,0]`, `W3 = [[2],[1]]`, `b3 = [1]`.
- 고객 A `[3,2]`: `Z1 = [3×1+2×2-4, 3×(-2)+2×1+1] = [3,-3]` → ReLU `[3,0]`. `Z2 = [3×1+0×1, 3×2+0×(-1)] = [3,6]` → ReLU `[3,6]`. 출력 `3×2+6×1+1 = 13`. 고객 B `[1,4]`의 출력은 24. 예측 `[13,24]`, 평균 제곱 오차 132.5.
- 역전파 기울기가 W1·W2·W3 전부에 대해 계산됐다(`dW1 = [[100,16],[280,64]]`, `dW2 = [[178,89],[96,48]]`, `dW3 = [[137],[130]]`).
- 학습률 0.01은 한 번에 너무 크게 고쳐서 정답을 지나쳤다(예측 `[0.81, 0.81]`, 손실 68.1). 학습률 0.001로 바꾸면 한 번 조정 후 예측 `[7.49, 14.82]`, 손실 26.4가 되었다.
- 0.001로 반복: 10회 `[6.98, 10.30]`(손실 7.2), 50회 `[9.63, 8.33]`(0.125), 200회 `[10.0, 8.0]`(0.0). 고객 2명뿐이라 맞추기 쉬운 설정이라 실제 일반화를 보여 주지 않는다.
