# inbox 2026-10-24 — Stock 프로젝트 주간 회고 (10/19~24)

> 출처: Claude Code 로컬 총괄 타워의 주간 요약(local-tower-digest). 파일 이름의 날짜가 속한 TIL 날짜다.
> 공개 저장소용으로 계정·경로·장비 이름·해시·종목별 수치는 뺐다. 수치는 탐색 단계 사후 보고이며 검증 결과가 아니다.

## 1. 이번 주 결정

- **에이전트 조직을 셋으로 나눴다.** 사람이 말을 거는 창은 "총괄" 하나로 두고, 수집·배포·파이프라인은 "운영 타워", 노트북 연구·피처 저장소는 "연구 타워"가 맡는다. 총괄은 직접 검증하지 않고 결정·우선순위·승인 전달만 한다. 세션 사이 메시지는 영어(토큰 절약), 사람에게 하는 말과 문서는 한국어로 쓴다.
- **스프레드 ≤10bp 진입 조건을 버렸다.** 목표로 하는 중소형 급등주를 대부분 걸러 버렸기 때문이다. 대신 필터 없이 실제 매도·매수 호가로 비용을 계산하고, 판정에는 편도 1/2 스프레드 스트레스를 건다. 결과를 본 뒤 이 스트레스를 줄이지 않는다는 조건을 미리 적었다.
- **실주문 실험은 계단식으로만 간다.** 모의 1주 → 실전 1주 → 종목당 소액 → 전략별 최적 금액. 첫 단계의 목적은 수익이 아니라 신호~체결 지연 실측이고, 지연이 일정 기준을 넘으면 증액하지 않는 게이트를 먼저 정했다.
- **피처 저장소 v1을 동결했다.** 조건은 "노트북과 집 PC가 각자 다시 만든 결과의 내용 해시가 같을 때만"이었고, 10일 모두 내용과 parquet 바이트까지 같았다.

## 2. 실패와 원인

- **정리 작업이 운영 환경을 지웠다.** 안 쓰는 작업 폴더를 정리하면서 한 가상환경을 지웠는데, 운영 콘솔 가상환경 4개가 `.pth` 파일로 그 패키지를 빌려 쓰고 있었다. 참조 검사가 `.pth`를 보지 않았던 것이 원인이다. 같은 경로에 잠금 파일 해시로 재설치해 복구했다.
- **"아무 일 없는 줄" 알았던 검색이 원본을 훑었다.** 데이터 폴더 루트에서 재귀 grep을 돌렸더니 수집 중인 원본 DB 폴더까지 읽었다. 이후 루트 재귀 검색을 금지하고 하위 폴더를 지정하게 했다.
- **잘린 목록을 전체로 읽었다.** 파일 목록 출력이 잘린 것을 모르고 "그날 검사 완료 파일이 없다"고 판단했다가 다음 날 정정했다.
- **용량 예측이 디스크를 같이 쓰는 다른 작업을 빼먹었다.** 백업 디스크가 2주 넘게 버틴다고 계산했지만, 같은 디스크에 들어가는 원본 주간 사본(한 번에 약 95GiB)을 넣으니 열흘 남짓으로 줄었다. 새 디스크 주문이 급해졌다.
- **같은 이름의 에이전트 창이 둘 생겼다.** fork해서 띄운 총괄 사본이 정리되지 않아 보고가 두 갈래로 흩어졌다.
- **PC 전원이 장중에 꺼졌다.** 같은 날 다시 시작하는 경로가 없어서, 재시작·검사 버튼 선행 조건을 다시 설계했다(1단계는 이번 주 배포 완료).

## 3. 바뀐 규칙

- 정리 전 참조 검사에 `.pth`·가상환경 설정을 포함한다. 운영 의존 폴더는 "정리 금지 목록"에 둔다.
- 데이터 루트 재귀 검색 금지. 원본 읽기는 승인된 시간 창·읽기 전용·잠금 파일로만 한다.
- 다른 세션이 전한 "사용자 결정"은 사용자 본인 확인 뒤에만 기록한다.
- 백그라운드 실행은 첫 진행 로그와 실제 인자를 확인한 뒤에 "시작됨"이라고 보고한다.
- 노트북은 두 모드로 운영한다. 같은 LAN이면 타워가 지시하고, 밖이면 사용자가 직접 결정한다.

## 4. 배운 점

- **사후 탐색은 검증이 아니다.** 유니버스를 잘라 수익 구간을 찾아봤지만, 하루 안에서 순서를 섞은 무작위 기준을 넘는 자르기는 없었다. 하루를 빼고 검증(leave-one-day-out)하면 표본 안의 최고 구간은 사라졌다.
- **지연은 공짜가 아니다.** 장 시작 1분 모멘텀 후보는 진입이 1초 늦어질 때마다 약 20bp씩 줄었다. 실주문 첫 단계가 지연 측정인 이유다.
- **분석 예산은 라벨을 보기 전에 고정한다.** 순열 검정 횟수와 트리 수를 실제 라벨을 붙이기 전에 사전 등록했다. 300트리로 늘리면 재학습만 30시간이 넘어서, 결과를 본 뒤 늘리고 싶은 유혹을 미리 막는 의미도 있다.
- **두 기계에서 비트까지 같은지 보는 것은 싸고 강력하다.** 동결 조건을 "해시 일치"로 정해 두니 논쟁 없이 동결할 수 있었다.
