## 1. 오늘 배운 것

### 1-1. 이미지 임베딩과 특징 추출기

- 이미지 임베딩은 이미지를 비교하거나 검색할 수 있도록 고정 길이의 수치 벡터로 표현한 것이다.
- Feature Extractor는 원본 이미지에서 색상·질감·형태 등의 유용한 특징을 추출하는 모델 또는 모델의 일부다. 학습된 표현은 모델과 학습 목적에 따라 달라진다.
- 사전학습된 ResNet18에서 표준 224×224 입력을 사용하면 마지막 합성곱 블록의 출력은 이미지 한 장당 (512, 7, 7)이다. 512개 채널마다 7×7 공간 위치의 반응값이 존재한다.
- 각 위치의 반응은 원본 이미지의 수용 영역(receptive field)에 의존한다. 7×7 지도를 원본 이미지의 서로 겹치지 않는 49개 조각으로 해석하면 안 된다.
- Global Average Pooling은 각 채널의 49개 값을 평균 내어 (512, 1, 1)로 축소한다. Flatten 이후 512차원 벡터가 된다.
- 최종 분류기(fc)를 Identity로 교체하면 분류 점수 대신 512차원 특징 벡터를 얻을 수 있다.

- Backbone은 특징 추출을 담당하고 Head는 추출된 특징으로 분류·탐지 등의 작업을 수행한다. 분류 Head와 Transformer의 attention head는 이름은 같지만 역할이 다르다.
- CNN은 합성곱을 이용해 공간적 국소 패턴을 학습한다. ViT는 이미지를 패치 토큰으로 나누고 Transformer의 self-attention으로 패치 간 관계를 학습한다. 어떤 구조가 더 적합한지는 학습 데이터, 사전학습, 해상도, 연산 자원, 작업 목적에 따라 다르다.

### 1-2. 유클리드 거리와 코사인 유사도

- 유클리드 거리: d(x,y) = √Σ(xᵢ−yᵢ)². 2차원뿐 아니라 3차원 이상의 벡터에도 동일하게 적용한다.
- 코사인 유사도: cos(x,y) = (x·y)/(‖x‖‖y‖). 벡터의 크기보다 방향을 비교한다. 영벡터에서는 정의되지 않는다.
- 유클리드 거리 자체에는 정규화가 필수는 아니다. 벡터 크기의 영향을 제거하고 싶을 때 L2 정규화를 적용할 수 있다.
- 두 벡터가 모두 L2 정규화되어 있다면 d² = 2−2cos(x,y)이므로 유클리드 거리 오름차순과 코사인 유사도 내림차순의 순위가 일치한다.
- 고차원 공간은 시각적으로 직관하기 어렵지만 수학적 거리 계산은 가능하다. 다만 차원이 커질 때 거리 집중 현상이 나타날 수 있어 데이터 분포와 거리 척도의 적절성을 확인해야 한다.

- Tensor는 여러 차원의 배열을 표현한다. 코사인 유사도를 구할 때는 벡터 축을 지정해야 한다. 예를 들어 (N, 512) 형태의 두 Tensor를 행별 비교하려면 `torch.nn.functional.cosine_similarity(a, b, dim=1)`을 사용하며 결과 Shape는 (N,)이다.

### 1-3. 이미지 군집화와 결과 해석

- 이미지 → 전처리 → 임베딩 추출 → 필요에 따라 정규화/차원 축소 → 군집화 → 대표 이미지와 이상 사례 검토의 순서로 접근한다.
- K-Means는 유클리드 거리 기반으로 군집 중심과 할당을 반복 갱신한다. 군집 수 K를 미리 정해야 한다.
- DBSCAN은 eps(이웃 거리)와 min_samples(밀도 조건)를 이용해 군집을 만들며, K를 직접 지정하지 않는다. 밀도가 낮은 점을 잡음(-1)으로 표시할 수 있지만 고차원 거리 집중이나 군집별 밀도 차이에 민감할 수 있다.
- 같은 이미지라도 임베딩 모델에 따라 색상 중심, 형태 중심, 의미 중심 등 서로 다른 군집이 만들어질 수 있다.
- PCA, t-SNE, UMAP 등으로 시각화할 수 있지만 2차원 투영에서의 거리와 군집 모양이 원래 고차원 구조를 그대로 보존한다고 단정할 수 없다.
- 군집 번호 자체에는 의미나 순서가 없다. 대표 이미지, 군집 크기, 경계 사례, silhouette score 등을 함께 검토한다. 비지도 군집을 정답 클래스와 동일시하지 않는다.

### 1-4. 이미지 분석 모델의 오류 분석과 개선

| 구분 | 의미 |
| --- | --- |
| TP | 실제 양성을 올바르게 탐지 |
| FP | 배경·잘못된 클래스·위치 불일치·중복 탐지 등으로 정답과 매칭되지 않은 예측 |
| FN | 실제 양성을 놓침 |
| TN | 실제 음성을 올바르게 음성으로 판단 |

- Precision = TP/(TP+FP), Recall = TP/(TP+FN), F1 = 2PR/(P+R).
- 객체 탐지에서는 배경의 가능한 음성 후보가 매우 많고 TN의 정의가 평가 방식에 따라 달라지기 때문에 일반적으로 TP·FP·FN을 중심으로 평가한다. 일반 이미지 분류에서 TN이 불필요하다는 뜻은 아니다.
- Confidence threshold를 높이면 낮은 점수의 예측이 제거된다. 일반적으로 FP와 함께 일부 TP도 줄어들 수 있으므로 Precision과 Recall의 교환관계를 검토해야 한다.
- 오류 사례를 작은 객체, 가림, 조명, 배경, 클래스 혼동, 위치 오차 등으로 나누어 원인을 분석한다. 데이터 보강, 라벨 품질 개선, 입력 해상도·모델·임계값 조정 등은 원인에 맞춰 선택한다.
- 개선 효과는 동일한 검증 조건에서 비교하고, 최종 테스트 데이터는 반복 튜닝에 사용하지 않는다.
- 오류 발견 → 유형 및 원인 분석 → 개선 가설 설정 → 통제된 실험 → 독립적인 결과 검토 순서로 진행한다. 개선이 실패했을 때도 원인과 검증 조건을 기록한다.

### 1-5. 객체 탐지 평가 복습: Confidence, IoU, AP/mAP

11월 23일의 객체 탐지·세그멘테이션 질문을 오늘의 오류 분석과 연결하여 복습한다.

- Confidence는 모델이 예측에 부여하는 점수다. 모델에 따라 클래스 점수 또는 objectness와 클래스 점수의 조합 등 정의가 달라지며, 반드시 보정된 확률인 것은 아니다. 코사인 유사도는 두 벡터 사이의 방향 유사성이다.
- Threshold는 특정 지표의 이름이 아니라 판단 기준값이다. Confidence·코사인 유사도·IoU에서는 보통 기준 이상을 허용하고, 거리에서는 기준 이하를 허용하는 식으로 사용한다.
- IoU(Intersection over Union) = 교집합 면적 / 합집합 면적. 정답과 예측 박스가 각각 (0,0,100,100), (50,0,150,100)이면 교집합 5,000, 합집합 15,000이므로 IoU = 1/3 ≈ 0.333이다. 두 영역 면적의 합으로만 나누면 안 된다.
- 일반적인 객체 탐지 평가는 클래스와 IoU 기준을 충족하는 정답 객체에 예측을 일대일 매칭한다. 동일 정답에 대한 추가 중복 예측은 FP가 될 수 있으며 매칭되지 않은 정답은 FN이다. 평가 세부 규칙은 데이터셋에 따라 다르다.
- AP(Average Precision)는 confidence 순으로 예측을 평가해 얻은 Precision–Recall 곡선을 요약한 지표다. mAP는 AP의 평균으로, 평균 대상은 클래스 및 평가 규약에 따른 IoU 임계값이다. AP50과 COCO 방식 AP(0.50~0.95, 0.05 간격 평균)를 구분한다.
- 세그멘테이션의 Mask는 객체 또는 클래스에 해당하는 픽셀 영역을 표시하며, 마스크 IoU는 박스 대신 픽셀 영역의 교집합과 합집합을 이용한다.
- Crop은 이미지의 일부 영역을 잘라내는 전처리/증강 기법이다. 정답 박스나 마스크, 수동 지정, 규칙 기반 방식 등으로도 만들 수 있으므로 반드시 기존 탐지 모델이 필요한 것은 아니다. Crop 이후 라벨 좌표 및 객체 잘림을 확인한다.

### 1-6. AI 하네스와 구독제의 경제성

- 모델은 추론을 수행하는 핵심 엔진이고, 하네스는 모델 호출, 도구, 권한, 컨텍스트, 세션, 검증 및 오류 복구 등을 구성하는 실행 환경이다.
- 동일한 모델도 채팅·작업 환경·CLI에 따라 도구와 실행 방식이 달라져 결과와 효율이 달라질 수 있다. 모델 성능과 하네스 성능을 분리해서 비교해야 한다.
- 하네스 락인은 모델 자체뿐 아니라 저장된 작업 흐름, 도구 및 인증 방식, 세션과 설정 등을 다른 환경으로 이전할 때 드는 비용과 관련된다. OpenCode 같은 범용 하네스도 제공사의 인증·이용 정책을 자동으로 우회할 수 있는 것은 아니다.
- SOTA(State of the Art)는 특정 시점과 평가 기준에서 최고 수준의 기술 또는 성능을 뜻한다. 모든 작업에서 최적이라는 의미는 아니다.
- 정액제 구독의 수익성은 사용자별 실제 추론 원가와 평균 사용량, 구독료, 운영비 등을 함께 고려해야 한다. 한도를 거의 모두 소진하는 이용자는 평균보다 높은 원가를 발생시킬 수 있지만, API 판매 가격을 실제 원가로 간주하거나 개별 구독자의 손익을 단정할 수는 없다. 완성형 서비스 판매와 토큰 판매의 장기적 수익성 역시 가설로 남겨 둔다.

### 1-7. 경제학: 메커니즘 디자인과 경매

- 게임이론이 주어진 규칙에서 참여자의 전략을 분석한다면, 메커니즘 디자인은 원하는 결과가 나오도록 규칙과 유인을 설계하는 접근이다. 풀프루프 설계와 비슷하게 개인의 올바른 행동에만 의존하지 않는다는 공통점이 있으나, 전략적 유인과 정보 제약을 다룬다는 점에서 구별된다.
- 매칭 이론은 지원자와 학교처럼 서로 선호가 있는 두 집단을 연결하는 문제를 다룬다. 안정 매칭은 서로 현재 상대보다 더 선호하는 미매칭 쌍이 없는 상태를 뜻한다.
- 1가격 밀봉 경매에서는 최고 입찰자가 낙찰되고 자기 입찰가를 낸다. 2가격 밀봉 경매(Vickrey auction)에서는 최고 입찰자가 두 번째로 높은 입찰가를 낸다.
- 독립적인 사적 가치의 표준 모형에서 2가격 경매는 자신의 가치를 그대로 입찰하는 것이 약우월전략이다. 1가격 경매에서는 경쟁 정도와 상대방 가치 분포 등을 고려해 입찰가를 낮추는 유인이 있다.
- 영국식 경매는 가격을 공개적으로 올려가는 방식이다. 표준 독립 사적 가치 모형에서는 2가격 경매와 유사한 결과를 낼 수 있다.
- 수입 동등성 정리의 표준 조건에서는 기대 낙찰대금이 같을 수 있지만 평균 입찰가까지 같다는 뜻은 아니다. 예를 들어 n명의 위험중립 입찰자의 가치가 독립적인 Uniform(0,1)이면 대칭 균형에서 1가격 입찰가는 (n−1)v/n, 2가격 입찰가는 v이다. 따라서 전체 입찰자의 기대 입찰가는 각각 (n−1)/(2n), 1/2이고 기대 낙찰대금은 두 방식 모두 (n−1)/(n+1)이다. 실제 경매에서는 위험회피, 공통가치, 입찰자 구성 등에 따라 달라질 수 있다.
- 반복 게임에서 Tit for Tat은 첫 회에 협력하고 이후 상대의 직전 행동을 따라 한다. 한 번 배신을 허용하고 두 번째 배신 이후 영구적으로 응징하는 규칙은 표준 Tit for Tat과 다르다. 반복 상호작용에서 보복, 용서, 오인 가능성을 함께 고려하는 문제로 연결된다.

### 1-8. 주식 상하한가와 복리의 비대칭

- 동일한 비율의 상승과 하락은 서로 상쇄되지 않는다. 가격 100을 기준으로 30% 상승 후 30% 하락하면 100×1.3×0.7=91이다. 순서를 바꾸어도 결과는 91이다.
- 일반적으로 (1+r)(1−r)=1−r²이므로 같은 크기의 반대 방향 수익률을 연속 적용하면 손실이 발생한다. 30% 하락에서 원금을 회복하려면 1/0.7−1≈42.86% 상승해야 한다.
- 그러나 상하한가가 같은 비율이라는 사실만으로 시장의 기대 가격이 하락하도록 편향되었다고 결론낼 수는 없다. 실제 상승·하락 확률, 수익률 분포, 거래 제한의 효과와 산술 기대수익률·기하 누적수익률을 구분해야 한다.
- 미국의 LULD(Limit Up–Limit Down)는 일정 기준 가격 대비 허용 가격대를 벗어난 거래를 제한하고 조건에 따라 거래를 일시 중단하는 제도다. 고정된 하루 상하한가와는 다르며, 재개 이후에도 조건을 다시 충족하면 반복 중단이 가능하다. 구체적 적용 기준과 개별 종목 사례는 별도로 확인한다.

## 2. 내가 궁금했던 질문과 이해한 답

### Q1. 마지막 합성곱 블록에서 512장의 7×7 특징 지도가 생긴다는 말은?

사진이 512장 생기는 것이 아니라 한 이미지에 대해 512개 특징 채널의 공간 반응을 계산한다는 뜻이다. 배치 크기가 N이면 출력 Shape는 (N, 512, 7, 7)이다.

### Q2. ResNet18의 fc 위치에는 무엇을 넣는가?

정답은 `nn.Identity()`이다. 기존 평균 풀링과 Flatten은 유지하고 최종 분류기만 제거한다.

### Q3. 상품 이미지 1,000장을 각각 512차원으로 표현한 배열의 Shape는?

(1000, 512). 행 하나는 이미지 한 장, 열 하나는 임베딩의 한 차원이다.

### Q4. 유클리드 거리는 4차원 이상에서도 같은 이름으로 부르는가?

그렇다. 인간이 공간을 직접 시각화하기 어려운 것과 거리의 수학적 정의는 별개다.

### Q5. 군집 결과가 임베딩 모델에 따라 달라지는가?

그렇다. 군집화 알고리즘은 주어진 특징 공간에서 작동하므로 특징 추출 모델이 무엇을 유사하다고 표현하는지가 결과에 영향을 준다.

### Q6. 정규화한 벡터에서 거리와 코사인 유사도가 왜 같은 순위를 만드는가?

두 단위 벡터 u, v에 대해 ‖u−v‖² = ‖u‖² + ‖v‖² − 2u·v = 2−2cos(u,v)이다. 단, 이 관계가 일반 K-Means와 spherical K-Means의 군집 결과까지 같게 만든다는 뜻은 아니다. 일반 K-Means의 군집 중심은 반드시 단위 벡터가 아니기 때문이다.

## 3. 개념 확인용 코드 예시 (미실행)

```python
import torch
from torch import nn
from torchvision.models import resnet18, ResNet18_Weights

weights = ResNet18_Weights.DEFAULT
model = resnet18(weights=weights)
model.fc = nn.Identity()
model.eval()

# Shape 설명용 가상 입력. 실제 이미지는 weights.transforms()로 전처리한다.
x = torch.zeros(2, 3, 224, 224)
with torch.inference_mode():
    embeddings = model(x)

# 예상 Shape: torch.Size([2, 512])
```

위 코드는 구조를 설명하기 위한 예시이며 직접 실행하거나 성능을 측정한 결과는 아니다.
